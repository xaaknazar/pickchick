# Изолированная визуальная проверка QR

7 октября 2026, Chromium headless, React Native web export, 820x1180,
deviceScaleFactor 1. Временный компонентный harness передавал синтетические
props настоящим PaymentScreen, ReviewScreen и EnrollmentScreen. Harness и
временная замена импорта App.tsx удалены сразу после export. Коммерческие
флаги и защищённое web-хранилище не изменялись. Это проверка композиции
компонентов, не E2E server checkout и не приёмка физического iPad.

Два визуальных прохода: обнаружены и исправлены светлый языковой переключатель
на светлом enrollment, устаревшая подпись телефонного счёта и лишняя иконка карты
под QR. Финальные снимки: payment-820x1180.png, review-820x1180.png,
enroll-820x1180.png. После снимка enrollment изменены только тексты: данные
выдаёт администратор; ошибка предлагает проверить данные и соединение.

На трёх экранах нет горизонтального overflow. Ошибок JavaScript и внешних
запросов нет; маршруты вне локального сервера были блокированы. QR из
отрендеренного изображения распознан Apple Vision VNDetectBarcodesRequest
и совпал побайтно с `https://qr.kaspi.kz/SYNTHETIC-LOCAL-FIXTURE-ONLY`.
Синтетический URL не открывался. Банковских операций и записей VPS не было.

Enrollment показан непосредственно для проверки компонента. В обычном TEST
web запуске KioskApp не включает enrollment (commercial flag выключен).
Защищённая запись, отказ серверного preflight, физическая клавиатура, VoiceOver,
сканирование телефоном и native SVG на iPad этим прогоном не подтверждены.

После финального снимка по решению владельца сокращена инструкция активного QR:
убрана фраза о повторной оплате. Под QR показан «Заказ №12» вместо «Kaspi · 12»;
на итоговом экране номер также получает №. Эти изменения текста проверены
адресным unit-тестом; дополнительный визуальный проход не запускался.
