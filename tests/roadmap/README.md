# Проверка пульта проекта - 16 сентября 2026

Проверен реальный Node HTTP/SQLite сервер и браузер Chromium. Данные ресторана
не менялись: отдельный временный каталог создаётся и удаляется тестовым runner.

- Семь Node тестов: источник и зависимости; вход/выход/Origin/cookie; конкурентная
  запись и история после перезапуска; валидация; смена ключа; лимит входа;
  точный русский текст при разбиении UTF-8 на сетевые пакеты.
- 13 Python проверок guard-условий выпуска.
- Браузер: вход файлом, 21 направление/83 задачи, пять разделов, поиск,
  пустой результат, deep-link, общая запись в двух браузерах, конфликт,
  сохранение текста при потере связи и завершении сессии, повторный вход,
  независимость фактов из репозитория, карточки при 1440/390/320 px.
- Скриншоты desktop/mobile просмотрены. Исправлены boolean `false` в тексте,
  пересечение подписей схемы, склонения и расширение grid на узком экране.
  Итог: нет JavaScript ошибок и переполнения страницы/карточки.
- Общие сборка, TypeScript, ESLint, форматирование, 78 unit, contracts,
  130 экранов каталога дизайна пройдены. Форматирование четырёх документов
  из предыдущего этапа приведено к существующему Prettier без изменения смысла.

```sh
node apps/roadmap/build.mjs
node --test apps/roadmap/test/*.test.mjs
python3 -m unittest discover -s infra/roadmap -p 'test_*.py'
python3 -m pip install -r tests/design/requirements.txt
python3 -m playwright install chromium
node apps/roadmap/test/run-browser.mjs
```

`ROADMAP_TEST_PYTHON` задаёт путь к отдельному Python окружению, если Playwright
не установлен в системном Python. Runner не использует публичную систему.
Оригиналы снимков находятся в `screenshots/`; они относятся к проверенному
кандидату до публикации и не доказывают установку на VPS.

Публичный выпуск и сохранение после перезапуска VPS проверены отдельно:
