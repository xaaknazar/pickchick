# Просмотренные фоны карточек

8 сентября 2026. Настоящий Expo web export из React Native-компонентов,
синтетические данные, API заблокирован. Перед съёмкой профиля дождались
полного исчезновения LaunchScreen, загрузки шрифтов и изображений.

- [Профиль 393](profile-393.png): исходный фирменный узор и градиент, имя/номер/редактирование.
- [Длинное имя, 320, текст 150%](profile-long-320-large.png): фон растёт вместе с содержимым.
- [Карточка Чиков 393](loyalty-393.png): прежняя композиция и выступающая вершина.
- [Карточка Чиков 320, текст 150%](loyalty-320-large.png): горы заполняют увеличенный блок донизу.

Это browser-проверка, не снимки физического iPhone. CSS-масштаб текста
использован для стресс-проверки размеров и не имитирует все особенности Dynamic Type.
