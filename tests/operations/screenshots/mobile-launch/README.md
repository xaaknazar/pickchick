# Заставка: визуальная проверка

Скриншоты реального Expo web export в Chromium, 8 сентября 2026. Шрифты
намеренно задержаны browser route, чтобы зафиксировать фазу запуска.
API заблокирован, Reduce Motion включён. CDP screenshot позволяет снять
экран без ожидания задержанных шрифтов. Это не снимки системного splash iOS.

- [320×568](launch-320.png): логотип, подпись и статус не пересекаются.
- [393×852](launch-393.png): цельный фон, центральная композиция, нижний статус.
- [Начало увеличения 393×852](animated-393.png): логотип растёт уже при
  задержанных шрифтах; подпись видна поверх слоя.
- [Раскрытие 393×852](reveal-393.png): крупный знак растворяется и открывает
  исходную страницу M01 под ним. Это промежуточный кадр перехода на 640 мс.

Начало и раскрытие просмотрены после уточнения владельца. Тест проверяет
рост до готовности шрифтов, монотонное увеличение без возврата, готовность
нижней страницы при исчезновении заставки и видимость подписи до раскрытия.
Автоматическая геометрия проверена на четырёх размерах в `tests/mobile/browser_launch.py`.
