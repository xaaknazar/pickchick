# Табло по исходному макету

8 сентября 2026. Визуальный источник:
[`display.html.txt`](../../../../design/reference-source/display.html.txt)
и предоставленный владельцем offline HTML, отрисованный с исходными шрифтами.
Снимки actual сделаны в Chromium с локальными HTTP fixtures, без реальных
заказов, телефонов, имён клиентов или ключей. Часы показывают время снимка.

- `actual-1920.png`: 1920×1080, шесть номеров приготовления и четыре готовых.
- `actual-1280.png`: та же композиция на 1280×720, номера показаны полностью.
- `actual-stale-1920.png`: последнее полученное состояние и явная потеря связи.

Снимки просмотрены рядом с оригиналом: сохранены фон, логотип, цвета,
пропорции колонок, шапка, карточки и нижняя строка. Имена, случайные ETA,
проценты и рекламные обещания из демонстрационного HTML не перенесены:
используются только доступные данные API и согласованные правила ТЗ.
