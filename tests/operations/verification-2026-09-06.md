Оба успешных режима завершились без ошибок JavaScript и неуспешных загрузок
ресурсов. Проверялись только заказы, созданные самим прогоном. Ключи служебных ролей
брались из приватных локальных файлов, в отчёты и скриншоты не включены.

Первый мобильный запуск T-000006 остановился на неоднозначном селекторе:
React Navigation сохраняет предыдущий экран в DOM. Заказ отменён с явной тестовой
причиной; harness теперь ограничивает селекторы текущим экраном. Затем T-000007
прошёл весь функциональный путь, но визуальный просмотр обнаружил многоточие
в крупном номере мобильного экрана. Исправление размера проверено повторным полным
прогоном T-000008 и измерением всего текста через DOM Range, а не только отсутствием
горизонтальной прокрутки страницы.

Ранний мобильный прогон T-000008 использовал operations web `922d16f` и API `32ab001`.
Проверенный мобильный bundle:
`/_expo/static/js/web/entry-e1148fc954656bef32c7b8807c72b86e.js`, SHA-256
`edc44c6b5ceba056c49e14370b7f6ad2919478d57317c968887ac05698e54b12`.
Продолжение истёкшей сессии не проверялось этим прогоном: соответствующее обновление
API на тот момент ещё не развёрнуто.
