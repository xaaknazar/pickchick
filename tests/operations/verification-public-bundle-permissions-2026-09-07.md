# Права публичного bundle при приватном umask

7 сентября 2026 проверен исходник
`f2700906cb48a5c410426abc04875114f9589c0b` в отдельном чистом worktree.
Это локальная проверка упаковщика и настоящего Linux-контейнера, а не выпуск
на VPS. Настройки серверов и cron не менялись.

## Реальная упаковка

`prepare-web.py` выполнен для этого SHA с `umask 077`, установленными
зависимостями и настоящей сборкой operations/backoffice. Весь checkout был
чистым до запуска; каталог результата находился внутри игнорируемой `.local`.
Проверено рекурсивно после создания manifest:

| Объект                                        | Число | Права  |
| --------------------------------------------- | ----: | ------ |
| Все публичные файлы, включая manifest         |   146 | `0644` |
| Все публичные каталоги, включая корень bundle |    13 | `0755` |
| Приватный родитель результата                 |     1 | `0700` |
| Синтетический env рядом с результатом         |     1 | `0600` |

Упаковщик расширяет права только внутри публичного output. Приватный родитель
и соседний env не стали доступны другим пользователям.

## Проверка без обхода файловых прав

Чтобы особенности macOS bind mount не скрыли ошибку UID, bundle и фактический
`gateway.Caddyfile` перенесены в отдельный fixture-owned Docker volume на Linux.
Владение файлами и каталогами установлено `1000:1000`. Caddy запущен под root с
`read_only`, `cap_drop: ALL`, единственным `NET_BIND_SERVICE`,
`no-new-privileges`, без сети наружу и без опубликованных host-портов.

Использован закреплённый image:

```text
caddy:2.11.4-alpine@sha256:5f5c8640aae01df9654968d946d8f1a56c497f1dd5c5cda4cf95ab7c14d58648
```

В `/proc/1/status` подтверждены `CapEff=0000000000000400`,
`CapBnd=0000000000000400`, `NoNewPrivs=1`: `DAC_OVERRIDE` отсутствует.
HTTP-запросы выполнены через localhost внутри этого изолированного контейнера.

- `/backoffice/`, `/backoffice/api.js` и
  `/design/prototype/assets/mockup/shot.jpg` вернули содержимое, SHA-256 которого
  совпадает с настоящим подготовленным bundle.
- Дополнительная синтетическая копия `api.js`, принадлежащая `1000:1000` с
  правами `0600`, вернула **403 Forbidden**. Это воспроизводит отказ чтения без
  добавления Caddy обходных capabilities.
- Fixture-контейнеры и volume удалены после проверки. Ранее работавшие локальные
  PostgreSQL cloud/edge и Redis остались запущены. VPS не использовался.

## Автоматическая регрессия

```sh
python3 -m unittest discover -s tests/operations -p test_public_bundle_permissions.py -v
```

Два теста прошли. Они запускают настоящий код копирования и `chmod` на временной
файловой системе под `umask 077`; только Git-ответы и этап компиляции заменены
изолированными fixtures. Первый проверяет весь публичный tree и сохранность
приватных прав. Второй проверяет отказ при изменённом упаковщике до сборки или
создания output. Docker-проверка выше выполнена отдельно, а не подменена этими
unit-тестами.
