Каждый размер использует собственную временную PostgreSQL schema. Создано по
6 синтетических заказов через доверенный доменный fixture. Один заказ проходит
prep → assembly → ready → handoff; итог `handed_over` проверен повторным чтением
PostgreSQL. Остальные нужны для состава визуальной очереди и удаляются вместе
со schema. Настоящие платежи, финансовый допуск облака, SMS и VPS не вызывались.

Проверка потери ответа не подменяет серверный успех: Playwright выполняет POST
через реальный gateway/edge и только после его ответа обрывает доставку браузеру.
UI сохраняет журнал, не рисует успех; после reload POST не отправляется сам.
Нажатие «повторить» отправляет тот же body / Idempotency-Key. Полный путь завершается
один раз, номера появляются на табло только после server-ready и исчезают после
выдачи. Роли и станции настоящие: cook не видит чужой station selector;
packer видит подготовленные части как контекст без чужих кнопок.

Дополнительные проверки:

- Неизвестный исход, 5xx, потеря подтверждённого ответа, перезапуск, отказ storage,
  конфликт 409 с явной сверкой, read-all pagination и FIFO после серверного UUID cursor.
  Ротация 1 000 номеров табло проверена по охвату всего списка и лимитам 6/4.
- HTML401, malformed JSON401, partial401, wrong-code403, wrong-pair403, invalid409,
  wrong-pair409 сохраняют вход/журнал. Только полный strict ErrorSchema с допустимой
  парой code/status разрешает отзыв доступа или ветку CONFLICT.
- Немедленный logout во время GET/POST. Поздний GET не перезаписывает новую сессию,
  поздний успешный POST не очищает оставшийся журнал. Повтор после нового входа
  подтверждает один эффект. Никакого автоматического повтора с новым ключом.
- Origin/Host/routes/query, JSON body 16 KiB, streaming response 3 MiB,
  запрет redirects/cookies/сторонних заголовков.
- Реальный offline-транспорт в браузере оставляет последнюю очередь с явной ошибкой.
  Реальный невалидный token не открывает рабочие элементы.
- Сохранённое через PG имя станции `</h1><button ...>` остаётся буквальным текстом,
  не создаёт DOM-кнопку. Пустая очередь видна, команд нет.

Все test HTTP servers закрыты, временные schema удалены в finally, fixture JSON
с credentials (0600, `.local`) удалены. Никакие существующие Docker volumes,
реальные данные или файлы доступа не очищались.
