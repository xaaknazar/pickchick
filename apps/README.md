# Клиентские приложения

Здесь будут отдельные workspace-пакеты `mobile`, `kiosk`, `pos`, `kitchen`,
`display` и `backoffice` согласно ТЗ. На этапе 1 созданы контракты и backend;
приложения ещё не реализованы. Макеты и их разбор находятся в `docs/research/`.

Первая полная версия дизайна: [каталог и handoff](../docs/design/README.md).
Исходник интерактивного прототипа — `design/prototype`, общие значения —
`packages/design-tokens`. При реализации переносить компоненты и контрактные
сценарии, не использовать демонстрационную логику прототипа как backend.
