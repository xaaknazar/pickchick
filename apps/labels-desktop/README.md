# PickChick «Маркировка»

Отдельная программа для Windows-моноблока: печатает наклейки на продукты на том же
чековом принтере Xprinter (рулон самоклеящейся бумаги вместо чековой ленты).

На наклейке: название продукта, когда изготовлено/вскрыто (дата и время), «ГОДЕН ДО»
(считается от срока годности продукта), срок, условия хранения и, по желанию, кто
маркировал.

- Плитки продуктов по группам, кнопки −/+ для количества наклеек, крупная кнопка «ПЕЧАТАТЬ».
- «Продукты» — таблица: группа, название, срок (мин / ч / сут), условия хранения.
  Стартовый список — примеры для кухни с жареной курицей; сроки ресторан задаёт сам
  по своим техкартам и санитарным правилам.
- «Журнал» — все напечатанные наклейки, файл `data\journal.csv` открывается в Excel.
- «Настройки» — принтер, способ печати, ширина/высота наклейки, отрезка, пробная наклейка.

Печать по умолчанию — ESC/POS: наклейка рисуется картинкой 203 dpi и уходит на очередь
Windows как RAW, затем частичная отрезка (`GS V 66 0`). Запасной способ — через драйвер.

## Сборка и установка на моноблоке

Нужен только .NET Framework 4.x, который уже есть в Windows 10.

```powershell
powershell -NoProfile -File infra\build.ps1                     # dist\PickChickLabels.exe
powershell -NoProfile -File infra\install.ps1 -Exe dist\PickChickLabels.exe   # от администратора
```

Установка кладёт программу в `C:\PickChickLabels`, данные — в `C:\PickChickLabels\data`
(сохраняются при обновлении), ярлык «Маркировка» — на общий рабочий стол и в «Пуск».

Проверки без окна: `PickChickLabels.exe --printers`, `--render label.png [продукт]`,
`--print [продукт]`.
