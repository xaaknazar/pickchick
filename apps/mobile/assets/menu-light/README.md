прежние синие `catalog-hd` изображения: эти файлы подключены только через

предметной приёмки владельцем описаны в [исходном протоколе](../catalog-hd/README.md).
Это отдельные локальные Dev-ресурсы; физическая приёмка ещё не выполнена.
