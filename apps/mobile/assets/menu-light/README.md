# Светлые фото меню - 27 сентября 2026

11 квадратных кадров 1254×1254 для главного меню. Страницы комбо используют
прежние синие `catalog-hd` изображения: эти файлы подключены только через
`src/menu-photo-assets.ts`. Тёплый светлый фон согласован с карточкой #FFF8EE.

Созданы встроенным `image_gen` по соответствующим фотографиям `catalog-hd`.
[Точные промпты и исходники](generation.json). Все результаты просмотрены;
еда не обрезается благодаря `contentFit="contain"`. Генеративная ретушь не
подтверждает рецептуру: прежние расхождения фото/состава и необходимость
предметной приёмки владельцем описаны в [исходном протоколе](../catalog-hd/README.md).
Это отдельные локальные Dev-ресурсы; физическая приёмка ещё не выполнена.
