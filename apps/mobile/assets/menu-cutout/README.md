# Вырезки для меню «Витрина» - 25 ноября 2026

По решению владельца (меню «Витрина», 25.11.2026) карточки меню 2 в ряд показывают

11 файлов WebP получены из прозрачных вырезок киоска `apps/kiosk/assets/v3/hd/<id>.png`
(источники и хэши в `../../../kiosk/assets/v3/hd/provenance.json`): обрезка по альфа-каналу,
длинная сторона 720 px, качество 86. Состав и ракурс те же, что у `menu-light/*.png`.
Подключены только через `src/menu-cutout-assets.ts` и только пока у позиции встроенное фото;
загруженное в бэк-офисе фото показывается в обычном окне.

Дополнение 25.11.2026 (владелец: «чтобы позиция чуть выходила за рамки, как у остальных»):
добавлены `burger`, `wedges`, `toast`, `sauce` (из `signature-60.png`) и `sauce-hot` тем же
способом. Фото, загруженные в бэк-офисе как вырезки (`cutout: true` в карте медиа), теперь
тоже стоят в окне «Витрины»: `src/menu-cutout-live.ts` хранит по хэшу фото рамку еды внутри
квадрата (каталог версии 21) и считает размер так, чтобы еда вставала на ту же линию и
поднималась над окном. У нового фото без записи берётся рамка по умолчанию.
