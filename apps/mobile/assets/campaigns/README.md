# Фон акции «7 + 1»

`combo-seven-plus-one.png` - новая иллюстрация акции с Burger Combo на спокойном
серо-синем фоне. Создана встроенным `image_gen` по существующему изображению
`../menu-light/burger-combo.png`; файл результата сохранён в проекте.
[Точный промпт](generation.json). Это рекламная иллюстрация, не подтверждение
перечня комбо, которые можно получить в подарок.

Текст и отметки накладываются интерфейсом. На фото нет зашитых чисел,
покупок или наград. Подходит для событий, профиля и компактной корзины.
