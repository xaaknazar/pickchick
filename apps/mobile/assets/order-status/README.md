# Персонаж статуса заказа

## Уточнение пакета с колой - 27 сентября

Через image_gen изменён пакет напитка: матовая передняя стенка перекрывает бутылку, видны боковые швы и закрытое дно ниже бутылки. Кола полностью внутри. PNG720×720 с alpha проверен в сцене «С собой»; персонаж и крафтовый пакет еды сохранены.

Создано 27 сентября 2026 по поручению владельца через встроенную генерацию изображений.
Визуальный источник бренда: `design/prototype/assets/mockup/logo.png`.
Скриншоты владельца задают композицию панели, но персонаж и бренд конкурента не копируются.

- `chef-cooking.png`: петух-повар PickChick, синий фартук, оранжевые рукава,
  корзина фритюрницы с фингерсами.
- `chef-assembly.png`: тот же повар складывает фингерсы в фирменный пакет
  на столе сборки.
- `chef-ready.png`: тот же персонаж подаёт поднос с готовой едой для зала.
- `chef-ready-takeaway.png`: выдача с собой, еда в крафтовом пакете и кола в отдельном пакете.

RGBA, 720 px по длинной стороне, прозрачный фон. Сцена декоративная, её блюда
не являются составом заказа: состав ниже берётся из сохранённого снимка API.
Это растровые 3D-иллюстрации, не rigged 3D-модель и не видео. По уточнению
владельца персонаж неподвижен: нет циклов, покачивания, переноса и вращения.
При смене серверного этапа Reanimated делает только crossfade 240 ms;
при Reduce Motion изображение переключается сразу.

## Продукция по оригинальным фотографиям - 27 сентября

Три сцены статуса заказа отредактированы через image_gen по оригинальным фото i4.jpg (фингерс), i9.jpg (Burger Combo, коулслоу, соус и Coca-Cola 0,5 л), i20.jpg (дольки). Сохранены персонаж, позы и композиции. В сборке виден наш бургер на фирменной бумаге; в выдаче заменены стандартные фри/стакан на дольки/бутылку из меню. Это декоративные растровые 3D-сцены, не состав конкретного заказа. Код переключения и crossfade240ms не изменён. Три PNG720×720 с alpha; HTTP200 и совпадение хешей всех трёх файлов, 3 теста статусов, iOS Dev bundle проверены. Визуально просмотрены подготовка/выдача393×852 и исходник сборки. Физическая приёмка отдельно; VPS/TestFlight/онлайн-пульт не обновлены.

Оригинальные референсы: `design/prototype/assets/mockup/`. Более ранняя HD-ретушь не использовалась как источник состава бургера: исходник Burger Combo показывает коулслоу. Сцены сохраняют прежние имена файлов, поэтому не требуют изменения путей приложения.

## Отдельная выдача с собой - 27 сентября

Для выдачи сохранён прежний поднос в зале и добавлена отдельная сцена «С собой»: еда в фирменном крафтовом пакете, Coca-Cola 0,5 л в отдельном прозрачном пакете. Выбор идёт по snapshot.service_mode сохранённого заказа при ready/fulfilled, а не по текущей настройке корзины. Приготовление и сборка прежние, crossfade240ms/Reduce Motion сохранены. Четыре теста статусов, typecheck, ESLint/Prettier и Impeccable detect прошли; PNG720×720 с alpha, asset HTTP200/hash и iOS Dev bundle проверены. CUA393×852 подтвердил готовый заказ «С собой» с двумя пакетами. Browser fixture обновлена под takeaway, полный browser suite не запускался; физическая приёмка отдельно. VPS/TestFlight/онлайн-пульт не обновлены.

Новая сцена получена через image_gen редактированием chef-ready.png. Упаковка иллюстративная по поручению владельца; сцена не описывает точный состав конкретного заказа.
