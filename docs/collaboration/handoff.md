## Продукт и код

Работающая сеть PickChick переходит с iiko (включая существующую Яндекс Еду)
на собственное ядро. В составе mobile, Windows POS, kiosk, кухня/сборка/выдача,
табло, backoffice, cloud API и автономный edge. ТЗ - `docs/01`–`docs/07`,
состояние задач - `docs/roadmap/project.json`. Срок четыре календарных месяца
включая внедрение, T0 не зафиксирована.

Клиенты - `apps/`; API/edge - `services/`; доменные пакеты - `packages/`;
миграции - `db/cloud/migrations`, `db/edge/migrations`; эксплуатация - `infra/`
и `docs/operations/`. PostgreSQL - источник истины. Сохранять idempotency,
outbox/inbox, владельцев агрегатов и финансовые инварианты из AGENTS.md.
Синтетический контур, неоплаченный POS-пилот и коммерческие операции различаются.
