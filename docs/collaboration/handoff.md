## Продукт и код

Действующая сеть PickChick переходит с iiko и подключённой Яндекс Едой на своё
ядро: mobile, Windows POS, kiosk, кухня/сборка/выдача, табло, backoffice,
cloud API и автономный edge. План - `docs/01`-`docs/07`, roadmap -
`docs/roadmap/project.json`. Срок четыре месяца с тестированием/внедрением;
T0 ещё не согласована. Работающую iiko не отключали.

Клиенты - `apps/`; API/edge - `services/`; домены - `packages/`; SQL -
`db/cloud/migrations` и `db/edge/migrations`; эксплуатация - `infra/` и
`docs/operations/`. PostgreSQL - источник истины. Сохранять idempotency,
outbox/inbox, владение cloud/edge и финансовые инварианты AGENTS.md.
Синтетический TEST, неоплаченная касса и коммерческое оформление различаются.

API `a0e198e5e682c7997c39a6e2be2b2387bb98fad7` установлен: статус обновляется событийным watch после commit,
а не обычным опросом раз в3 секунды. После background/обрыва - snapshot;
старый API получает fallback. CI36119864030 полностью зелёная, публичный цикл
`T-000040` проверил приготовление/сборку/табло/выдачу и восстановление сети.
Протокол: `docs/operations/mobile-order-events.md`; iPhone пока принимает владелец.
Внешний gateway обновлён только для PickChick; 20-секундный heartbeat проверен.

maintenance; writer запускается от UID владельца только с одним RW-файлом.
38 прежних заказов не изменились. Не повторять apply поверх установленного a0e198e.
Режим/ключ отправки сохраняются при потере ответа и перезапуске.
