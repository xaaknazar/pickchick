## Статус

Установлены официальный marketplace и нативный плагин ECC в Codex, а также
project-плагин Claude в рабочей копии этой задачи. Обе регистрации подтверждены
штатными `plugin list`: версия 2.2.3, enabled=true. Существующие установки Claude
в других копиях не удалены; изменения их файлов не выполнялись.

Общий профиль в AGENTS/CLAUDE и skills, минимальный режим Claude без автоматического
сохранения переписки/обучения, собственный короткий SessionStart, read-only отчёт
об изменениях и шаблон передачи. Платный сервис и GitHub App не подключены.

## Решения и ограничения

- Мастер upstream ECC dry-run предложил миграцию с удалением local-регистрации
  другого проекта; apply не выполнялся. Проектная установка выполнена штатным CLI.
- Корневой checkout отстаёт от общего среза и содержит `Claude outputs/`.
  Он сохранён; задача сделана в отдельной рабочей копии от свежих refs.
- Установлен pnpm 11.25.0, проект требует 11.19.0. Freshness/claim выполнялись
  непосредственно штатным `project-sync.mjs`; глобальный pnpm не менялся.
- Профили hooks Claude не равны Codex hooks. Нативное доверие Codex `/hooks`
  не подделывалось, автоматический запуск его hook не заявляется.
- Общие статус и roadmap зарезервированы `desktop-kitchen-046-1117`, онлайн-пульт
  `pick-box-1112`. Запись в этом журнале/PR, без перезаписи занятых файлов и пульта.
- Контекст по путям помогает выбрать проверки, но не вычисляет все зависимости
  и не заменяет чтение diff. Передача между физическими Mac требует fetch/commit.
