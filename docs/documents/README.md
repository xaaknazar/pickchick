# Документы PickChick

Здесь собраны документы проекта для владельца, управляющего и персонала: схемы, план запуска, памятки и сценарии проверок. Технические документы для разработчиков лежат в соседних папках `docs/`, ссылки на главные из них - в конце страницы.

PickChick - собственная система ресторана PickChick в Алматы (Peak Group): касса, кухня, приложение, киоск, бэк-офис, склад и учёт. С 19.11.2026 ресторан работает только на PickChick. iiko, iikoTransport, Kwaaka и AILILLU отключаются.

## Как пользоваться

- **Рабочие версии памяток** - документы Claude на claude.ai. Их правят и комментируют. Здесь, в GitHub, хранятся версии на дату: при каждом заметном изменении Claude обновляет файлы в этой папке.
- **Пометки в памятках:** «пока вручную» - система этого не делает, на запуске делаем руками; «будет к запуску, проверить на обучении» - экран ещё доделывается; «уточнить у управляющего» - решение ещё не принято.
- **Живой трекер** «Запуск PickChick» - на claude.ai. Снимок в этой папке - копия на дату.
- Все номера заказов, суммы и имена в примерах выдуманы. Паролей, ключей и данных гостей здесь нет и быть не должно.
