# Мобильное приложение: три языка и push, 14.10.2026

Задача `mobile-l10n-push-1014`, ветка `codex/mobile-l10n-push-1014`.
Владелец разрешил временную передачу пересекающихся файлов для переводов и push,
с сохранением изменений оплаты, Luma, TipTop, device-center и жестов игр.

## Объём

- Русский, казахский и английский интерфейс, сохранение выбранного языка.
- Сопоставление текстов: [RU / KK / EN](../translations/mobile-ru-kk-en.md).
- Согласия на статусы заказов и предложения разделены. Системное разрешение только
  после явного действия гостя. Веб не выдаётся за поддержку нативных push.
- APNs/FCM напрямую; флаг `CUSTOMER_PUSH_ENABLED=1` выключен по умолчанию.
- Уведомление не подтверждает оплату. Открытие проверяет принадлежность сообщения
  текущему аккаунту, затем открывает заказы с чтением серверного состояния.
- Токены устройств шифруются; отзыв сеанса и удаление профиля прекращают доставку.
- Снимок последнего состояния заказа записывается в PostgreSQL с дедупликацией.
  Промежуточные состояния между опросами могут не отправиться. При неопределённом
  сетевом результате возможен повтор баннера; inbox остаётся без дублей.

## Проверки и состояние

- Сборка всех workspace и typecheck прошли; lint прошёл.
- Mobile: 367 тестов и 50 Python-проверок. Root unit: 248 прошли, один
  PostgreSQL-сценарий пропущен в unit и отдельно выполнен с локальной БД.
- Push: 5/5, включая миграцию059 на PostgreSQL18, согласия, изоляцию аккаунтов,
  зашифрованный токен, ротацию, конкурентные worker, retry и logout.
- Браузер: RU/KK/EN, повторное открытие, вкладки, имя гостя, честное отключение
  push в web на 393×852 и 320×568. Скриншоты локально `.local/l10n-push/screens/`.
- HTML-документ: 1341 строка (1333 UI + 8 заголовков/текстов push), поиск и фильтры
  проверены. Генератор `node scripts/mobile/translations.mjs --check`.
- Объединён свежий shared `6d8db476`: все игры сохраняют полноэкранный маршрут;
  PickMan возвращается к заказу. Изменения второго Mac сохранены.
- Полная CI/PR готовятся. Новый бинарник, APNs/FCM на физическом устройстве,
  маркетинговая кампания, серверный выпуск и App Store не проверены/не выполнялись.
- Онлайн-пульт не опубликован; ресурс публикации занят другой работой.

Каталог, цены, банк и App Store не изменялись. Реальные push не отправлялись.
Доставка провайдером на iPhone пока не подтверждена. Полный CRM-push не отмечен готовым.

## Для включения после приёмки

Миграция 059, отдельный ключ шифрования токенов, APNs key/team/topic, entitlement
и профиль iOS; для Android - отдельные FCM credentials и google-services.json.
Секреты только в защищённых внешних файлах. Подготовленный процесс:
`node services/api/dist/customer-notifications-worker.js`.
Нужны резервы серверных ресурсов, backup/restore и штатные проверки релиза.

Настройка и ограничения: [runbook](../../infra/notifications/README.md).
