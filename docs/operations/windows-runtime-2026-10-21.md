# Касса: выпуск runtime 21 октября 2026

Владелец поручил выпускающему Mac завершить финансовую приёмку и продолжить
выпуск. Этот документ пока фиксирует подготовку, а не установку.

## Фактическая исходная версия

Read-only проверка 21.10: семь служб работают, схема кассы020. Edge и
DeviceAccessWorker используют `5b6f846b80785f915e9f8dd7d45fa72fd4bc13ee`,
FulfillmentWorker и MenuSyncWorker - `23fb39e152fccaa97a32e9bf179c2d89a50dc1d5`.
Следовательно, отдельные инструкции021 ->022 ->023 нельзя запускать прямо
на этой базе. Нужен атомарный переход020 ->021/022/023.

Резерв `@windows/cashier` остаётся у photo-printer-recovery. До согласованной
временной передачи установка не начинается; чужая задача и её файлы сохраняются.
SSH использует прежний закреплённый fingerprint, его проверка не отключается.

## Подготовленный оператор

`infra/windows/update-runtime-1021.ps1` по умолчанию только проверяет. Требует
чистого опубликованного исходника, полной Foundation CI точного SHA, архива
с пофайловым manifest, исходных XML и их хешей, неизменённых старых бинарных
файлов, завершённой копии/пробного восстановления schema020 не старше6ч.

Предварительно выполняется `backup-native-service.mjs` с аргументом `schema020`
из защищённого EdgeTools; дамп и manifest остаются в закрытом каталоге Windows.
Общий мигратор, старый backup-native-edge.ps1 и установщики019 не используются.

После проверки и `-Apply`: общая файловая блокировка native maintenance,
новый неизменяемый runtime, остановка Fulfillment/MenuSync/DeviceAccess/
KitchenLink/Edge, одна транзакция трёх миграций, замена четырёх XML только
в частях пути к runtime, запуск в обратном порядке и проверка дочерних процессов.
PostgreSQL, tunnel, POS-приложение, конфигурация, ключи, цены и флаги не меняются.

`runtime-schema-1021.mjs` проверяет точную историю020, единственную точку,
три ограниченные роли и права оператора на чтение системного идентификатора.
До и после сравниваются все прежние столбцы/строки, последовательности и права.
Добавляются только права новых функций и таблицы presence. При любой ошибке
все три миграции откатываются одной транзакцией. Повторное применение запрещено.

## Проверки и восстановление

- PostgreSQL: атомарный переход, искусственный сбой023, полный rollback,
  сохранность данных/прав, новые ограниченные права и отказ повторного запуска.
- Windows PowerShell5.1: 26 проверок в памяти с подменёнными SCM-командами;
  проверяются точная замена путей, отказ чужим XML/зависимостям, остановка всех
  писателей и восстановление служб после частично неудавшейся остановки.
- Хеши импортируемых штатных помощников проверяются отдельно.

До запуска новых процессов при ошибке замены XML возвращаются исходные
привязки. После запуска новый runtime может записать данные нового формата:
автоматический возврат старого обработчика запрещён. Сохраняются совместимые
новые привязки, закрытые свидетельства и требуется исправление вперёд.
Схему023 и рабочие данные назад не откатывать и не удалять.

После фактической установки сюда добавить SHA, полную CI, хеш архива/копии,
результат семи служб, readiness, heartbeat и отдельно приёмку владельца.
Акция7+1 остаётся выключенной до проверки нового FulfillmentWorker и отдельного
решения о включении. Реальные счета, QR и платежи для проверки не создаются.
