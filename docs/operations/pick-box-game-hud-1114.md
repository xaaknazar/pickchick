# Pick Box - игровой интерфейс по краям, 14 ноября 2026

## Статус

По уточнению владельца центр освобождён: счёт с иконкой коробки и рекорд слева,
текущая вершина и прогресс справа, жизни рядом с паузой. Центральный заголовок
удалён. Постоянные сообщения о полёте/ожидании больше не занимают экран;
доступная подсказка поля сохраняется. Короткая первая подсказка и сообщения
о попадании/промахе появляются слева под счётом.

Крепление по центру поднято в свободное пространство между показателями.
На 393x852 его центр теперь y=106,65 вместо y=242,56 в предыдущем предпросмотре.
На первом сбросе при том же положении коробки верёвка длиннее примерно на 136 px.
Тела коробок по-прежнему имеют отдельную область отсечения, верёвка может
выходить выше игрового поля. Физика и правила игры не менялись.

Обложка, исходные изображения, звуки и параметры выпуска сохранены. Это
предпросмотр для владельца. Новые сборки в TestFlight и Google Play не отправлены.
Разрешение на следующий тестовый выпуск требуется после показа этих снимков.

## Примеры и решение

Просмотрены реальные игровые снимки
[Tower Bloxx New York](https://www.touchandplay.ru/games/tower_bloxx_new_york/review/tower_bloxx_new_york_golovolomka_sitibilder-43402/)
и [Stack](https://www.pocketgamer.com/zigzag/8-ketchapp-games-to-play-after-finger-spinner/).
У Tower Bloxx показатели расположены по краям; у Stack мало элементов поверх
башни, хотя его счёт расположен по центру. Для Pick Box выбран первый принцип
с уменьшенным количеством текста, по прямому запросу владельца. Чужие картинки,
шрифты и графика не копировались в приложение.

## Доказательство

- 23 теста Pick Box PASS, включая устойчивую башню до космоса. TypeScript,
  адресный ESLint и production web export PASS. Проверка компоновки инструментом
  дизайна не выявила замечаний.
- Семь тестов пульта проекта PASS после обновления записи Pick Box.
- Реальная браузерная игра: прямой вход без заставки, первый сброс дал счёт 1
  и рекорд 1; прогресс изменился с 0/8 на 1/8. Пауза и полный отсчёт продолжения
  проверены; после отсчёта сброс снова доступен.
- 320x568, 393x852, 768x1024 и 844x390: показатели по разные стороны точки
  крепления, горизонтального переполнения нет. Отклонение крепления от центра
  менее 0,01 px. В финальном браузерном прогоне ошибок страницы нет.
- Снимки: [обычный экран](pick-box-1112/game-hud-393.jpg),
  [маленький экран после первого попадания](pick-box-1112/game-hud-320.jpg).
  Это снимки локального web-предпросмотра React Native, не новой нативной сборки.
- Старый Python/Playwright-сценарий обновлён под новый HUD, но не запускался.
  Нативная проверка, большой системный шрифт и физическая приёмка этой правки
  не выполнены. Полная CI потребуется перед следующим тестовым выпуском.

## Откат

Возврат интерфейса к коммиту 3d0306f7 без миграции данных. Уже распространённые
тестовые пакеты 36/10 этой правкой не затронуты.
