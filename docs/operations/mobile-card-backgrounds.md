# Фоны профиля и карточки Чиков

8 сентября 2026 по просьбе владельца доработаны фон первой карточки профиля
и заполнение фона «Чики за любимый вкус».

В M30 использован оригинальный `bg-blue.png` из макета mobile-v2: приглушённый
узор с логотипом и тёмный синий градиент поверх него. Номер и действие
редактирования чуть крупнее и контрастнее. Декоративный слой заполняет всю
карточку внутри рамки, обрезается по скруглению, не получает нажатия и скрыт
от accessibility tree. Вход, данные, маршруты и восстановление аккаунта сохранены.
Горный фон карточки Чиков в профиле теперь закреплён по четырём сторонам,
без процентных width/height относительно внутренней области.

На витрине обнаружен отдельный дефект: SVG `skyline.svg` сохранял пропорции
внутри растянутого Image. При росте карточки из-за текста в ней возникала
незаполненная область. Для этой карточки добавлен `skyline-card.svg` с
`preserveAspectRatio="none"`; остальные символы файла совпадают с оригиналом.
Общий исходный asset, цвета, контуры, размер и положение карточки сохранены.
Прежняя формула оставляет вершину на 6 px выше блока; она не обрезается.

Проверены:

- Mobile TypeScript, ESLint/Prettier и Expo export для web/iOS/Android.
- Существующий browser_profile.py: гость, вход, длинное имя, редактирование,
  помощь, уровни, выход и ошибка восстановления на 320/393.
- 36 сочетаний геометрии двух карточек: 320/393/430, гость/короткое/длинное имя,
  текст 100%/150%. Фоны доходят до рамки с отступом 1 px по четырём сторонам;
  горизонтального overflow нет, изображения загружены. Кнопки не меньше 48 px.
- 12 снимков витрины до/после на 320/393/430 и тексте 100%/150%: высота
  карточек не изменилась, фон заполнен донизу, выступ вершины сохранён.

[Просмотренные скриншоты](../../tests/operations/screenshots/profile-backgrounds/README.md).
Использованы синтетические аккаунты, API в browser-проверках заблокирован;
ошибок JS и API-записей нет. Увеличение текста через CSS - проверка геометрии,
не аппаратная проверка iOS Dynamic Type. iOS/Android export также не заменяет
визуальную приёмку на телефоне. Новых native-зависимостей нет, изменения
передаются через существующий Metro в PickChick Dev; TestFlight не обновляется.
