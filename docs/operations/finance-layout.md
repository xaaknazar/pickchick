# Финансы: выравнивание фильтров и журнала

7 октября 2026, задача finance-layout на финансовом Mac. По скриншотам владельца
исправлены разная высота полей, смещение кнопок и неоправданные пустоты.

Период и подразделение объединены в одну группу. Поля/кнопки высотой 48 px
стоят на общей линии; ширина распределяется сеткой по доступному месту.
Быстрые периоды имеют состояние aria-pressed. Вкладки образуют равномерную
сетку. Подсказка поиска вынесена под строку и связана через aria-describedby.
Стрелки select отрисованы CSS при сохранении нативного списка и клавиатуры;
в forced-colors возвращается системное оформление. Data URI не используются.
Таблица журнала больше не наследует 34% ширины первого столбца каталога:
место отдано документу и статье, суммы выровнены вправо.

Изменены только finance.ts и ограниченные finance-селекторами стили.
Расчёты, права, API, БД, отмена и повтор операций не изменены.

- CUA Chromium 1440, 768, 375: нет горизонтального переполнения страницы.
  На desktop все восемь элементов фильтров имеют высоту48; верхние координаты
  совпадают внутри каждой строки. Поиск Enter и пустое состояние проверены.
- Снимки содержат только синтетические данные:
  [компьютер](images/finance-layout/journal-1440.png),
  [телефон](images/finance-layout/journal-375.png).

Применены UI/UX Pro Max и Impeccable layout/craft-floor. Загрузчик Impeccable
не имел execute permission; использованы прочитанные руководства и существующий
дизайн проекта, настройки установленного skill не изменены. Первая визуальная
проверка выявила CSP-запрет data URI стрелки и разницу дат на2px; исправлено,
повторная проверка прошла. Механический detector не запускался из-за launcher.

## Выпуск

До публикации source обязательна полная CI. Разрешён только public/backoffice
overlay: API/current, база, настройки и маршруты остаются прежними. Резервы
@vps/public и @vps/gateway заняты finance-layout. Исходные pointers подтверждены
на368c4e8, gateway SHA256
0bb039bde008cd3a25aeec3d4e06d15f3ad5e8dc3f6eda2e8373fd004264d3ff.
Перед переключением повторно сверить baseline и держать общий owned lock.
Сохранить старый immutable public release для отката; проверить manifest,
неизменность остальных assets/контейнеров и фактические mounts после запуска.
Новая установка и результат CI фиксируются ниже только по факту.

Общие project-status/roadmap/handoff остаются в резерве farm-gameplay-v2;
онлайн roadmap принадлежит tiptoppay-test-rollout. Факты передавать этим
протоколом и журналом координации, не перезаписывать чужую работу.
