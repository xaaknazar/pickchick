# Киоск 18 - серверное снятие ограничения строк

Подэтап `kiosk-owner-polish-1013`, изолированная ветка
`codex/kiosk-cart-lines-api-1013` от установленного API
`5b6f846b80785f915e9f8dd7d45fa72fd4bc13ee`, schema058.
Первоначальный baseline ad713 сменился после установки device-center; новая
установленная версия явно интегрирована, без всего shared.

Владелец разрешил временную передачу `@vps/api` от device-center. Резерв
передан серверному подэтапу той же доработки. Получены свежие refs; отставание
от shared намеренное: облачная кухня и другие неопубликованные серверные
изменения сюда не переносятся.

Изменены только проверки числа строк во входе киоска, расчёте цены, снимке
расчёта и ответе заказа. Ограничения размера запроса, денег, количества одной
конфигурации, доступности и идемпотентность остаются. Цены, каталог, банковские
адаптеры, флаги, compose, права БД и миграции не меняются.

13 проверок изолированного PostgreSQL прошли, включая 201 различную
конфигурацию, сохранение расчёта/заказа и 0 платёжных попыток.
Отдельно обнаружен прежний предел 200 в приёмнике кухни; исправление и его
установка проверяются отдельно. Создание большого заказа не является
доказательством доставки на установленную кухню.

Оператор `infra/staging/release-kiosk-cart-lines.py` требует точные SHA/image/
compose/gateway, опубликованный чистый коммит и полную зелёную CI. Runtime
ограничен хешами пяти проверенных файлов. Сохраняются общая блокировка,
шифрованный backup, пробное восстановление в отдельную БД, проверка ACL,
соседних контейнеров и CAS указателя. Владелец разрешил временную работу с `@vps/postgres` только для backup/restore. Обновление API пока не выполнено.
Откат на прежний reader запрещён при наличии снимков свыше 200 строк;
данные сохраняются, потребуется совместимое исправление вперёд.
