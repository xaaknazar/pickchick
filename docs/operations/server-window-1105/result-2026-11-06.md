## Разбор проверки

В локальном оркестраторе обнаружено неверно широкое сравнение всех Labels
контейнера API. Docker Compose может менять служебную метку конфигурации
при разрешённом обновлении окружения. Требовалось отдельно проверять
закреплённый образ и OCI revision, а также точный diff окружения.
Однако обработчик ошибки сохранил только тип AssertionError, без текста и
строки. Поэтому нельзя доказанно приписать остановку именно этому сравнению:
другие assert выполнялись раньше. Повторной установки для диагностики не было.
Перед новой попыткой нужны именованные проверки и безопасный журнал этапов,
проверка фактической структуры auth/config и тест смены служебных меток.
Защиты образа, revision, окружения, соседей, БД и активных оплат сохраняются.
