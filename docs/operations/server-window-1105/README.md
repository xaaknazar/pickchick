### Почему без 072

В shared `packages/pos-order-sync/src/kitchen-cloud.ts` проверяет наличие таблиц
072 и новые права. При установленных таблицах без новых прав обычное событие
кухни получает CONFLICT. Поэтому одного добавления DDL в старый owner-скрипт
недостаточно для доказательства совместимости с кассой 020. По заранее заданному
решению владельца выбран fallback 069-071. Миграция 072, PR304 и новые права
пойдут отдельным согласованным шагом. Полная совместимость нового runtime с 020
здесь не объявляется проверенной.

В fallback CustomerIdentity и customer-controller не отличаются от c3a0fbee.
Изменения combo-rewards присутствуют в ранее проверенном ffb2fd23, флаг акции
не меняется. Единственное дополнение к зависимостям - точная копия пяти файлов
из `90f83a1d` (готовое исправление node-forge), без нового исключения из аудита.
Оператор сравнивает эти файлы с указанным коммитом. Также перенесён точный
календарный тест кабинета из shared `a45fe6f8`: после reload он явно выбирает
месяц искусственных данных. Финансовая логика не меняется; файл закреплён
проверкой источника оператора.
