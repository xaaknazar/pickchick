# Плавающая капсула вкладок и повторное нажатие - 02.11.2026

Решение владельца: одна активная капсула упруго перемещается между вкладками;
повторное нажатие на выбранную вкладку плавно возвращает страницу наверх.
Обычное переключение сохраняет место прокрутки. Форма, цвета и подписи сохраняются.

## Подготовлено

Отдельная рабочая копия и ветка `codex/mobile-tab-motion-1102`, база shared
`35a314753e4f1c05868a6b2f8f5dc336c3d20261`.

- `TabActiveCapsule`: один постоянный элемент; spring по translateX на native driver.
  При смене направления движение перенаправляется из текущей позиции.
  Размеры поступают из фактической разметки вкладки. Переразметка и Reduce Motion
  переключают положение непосредственно, без пространственной анимации.
- `useTabScrollToTop`: штатный `useScrollToTop` из установленного Expo Router;
  учитывает активность вкладки и preventDefault. Прокрутка отключает анимацию
  при Reduce Motion; необязательный callback сбрасывает выбранную секцию меню.

Эти компоненты пока не подключены к интерфейсу. Это подготовка, не готовая функция.
