# Плавающая капсула вкладок и повторное нажатие - 02.11.2026

Владелец поручил перемещать активную капсулу между вкладками с пружиной и
возвращать страницу наверх повторным нажатием. Обычное переключение сохраняет
место прокрутки. Цвета, подписи, testID, казахские шрифты и оплата сохранены.

## Реализация

Ветка `codex/mobile-tab-motion-1102`, база shared `35a31475`.
Включён опубликованный checkpoint `c7fcb709` из PR302 с сообщением о закрытом
ресторане. Этот merge выполнен только в рабочую ветку, не в shared.

- Одна постоянная капсула за кнопками вместо отдельной подсветки каждой кнопки.
  Позиции и размеры измеряются по реальной разметке, включая изменение ширины.
- Spring по translateX на native driver: stiffness 340, damping 29, mass 0.85.
  Быстрое переключение перенаправляет текущую анимацию. Внутренняя область
  устраняет смещение от рамки; новые размеры и Reduce Motion применяются сразу.
- Повторное нажатие на «Меню» и «Заказы» плавно прокручивает их наверх.
  Используется штатный useScrollToTop установленного Expo Router с проверками
  фокуса и preventDefault. Смена вкладки не сбрасывает позицию списка.
- При Reduce Motion прокрутка наверх происходит без пространственной анимации.
  Для меню сбрасывается только ожидание программного перехода к категории.
