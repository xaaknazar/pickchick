# Скриншоты Google Play из материалов App Store

06.11.2026 владелец поручил взять ранее сгенерированные материалы App Store.
Четыре производных сохранены в черновике стандартной RU-карточки Google Play.
Для переводов без локализованной графики Console использует графику RU.

1. `01-menu.png` - главное изображение меню, без обещания подарков.
2. `02-sharing.png` - наборы на компанию. Цены первых трёх наборов сверены
   с опубликованным каталогом v11: 13990, 26990, 39990 KZT.
3. `03-combo.png` - верхняя часть Master Combo без тестовой цены 100 KZT.
4. `04-games.png` - мини-игры из исходного набора.

Размер каждого изображения 1080x1920, RGB PNG без прозрачности, менее 8 MB.
Заголовки русские, исходный интерфейс английский. Сохранены Алекс, фирменные
цвета и композиции. Рамки iPhone и системные элементы iOS исключены.
Изображение заказа с 17 KZT и рекламный заголовок с подарками не перенесены.

Это маркетинговая адаптация через встроенный image_gen, а не съёмка Android.
Исходный комплект и App Store не изменялись. Проверка на Android-телефоне и
вычитка казахского текста остаются отдельными незавершёнными пунктами.

`manifest.json` содержит точные промпты, ссылки на локальные исходники,
их SHA-256, параметры экспорта и SHA-256 финальных файлов. Два более высоких
мастера обрезаны по центру до 9:16, затем все экспортированы в 1080x1920.

Откат: удалить или заменить четыре объекта только в черновике Google Play.
Публичный выпуск требует отдельного разрешения владельца.
