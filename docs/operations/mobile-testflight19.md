# PickChick iOS 0.2.0 (19)

Подготовка по поручению владельца от 12 октября 2026. Профиль `storefront`:
опубликованный каталог, серверный вход/Kaspi, без Pick Farm и без тестовых
неоплаченных заказов. Исходник для архива - shared после включения редизайна
PR #233 и `codex/mobile-bugfix-1012`, включая отступ кнопки Kaspi.

## Состояние выпуска

Номер 19 подготовлен. Архивирование, export, upload и обработка Apple ещё
не выполнены. Их нельзя считать успешными по одному изменению номера сборки.
Полный SHA, CI, хеш IPA и результат Apple будут записаны после соответствующих
проверок. Каталог, цены и реальные платежи этим выпуском не меняются.

## Чек-лист владельца на iPhone

После появления 0.2.0 (19) обновить PickChick через TestFlight.

- **Рестораны:** «Открыто»/«Закрыто» соответствует текущему времени Алматы;
  «Открыть в 2ГИС» запускает установленное приложение.
- **Заказы:** счётчик на вкладке; карточка «Сейчас» и переход к оплате; история
  по дням; звёзды для оценки только у последнего заказа. Кнопка «Открыть Kaspi»
  целиком видна над нижним меню. Новые счета/платежи без отдельного согласия
  владельца не создавать.
- **Трекер:** карусель игр; «Играть» открывает игру на весь экран; плитки «Чек»
  и «Поддержка» в предусмотренных сценарием состояниях. В Kaspi «Чек» показывает
  статус, «Поддержка» отсутствует, как отмечено в протоколе редизайна.
- **Исправления:** 20 быстрых переключений Меню ↔ События без пустой страницы;
  в Pick Blocks, открытом из заказа, свайп вниз ускоряет падение; фотографии
  напитков владельца; часы «10:00-00:00».

Физическая приёмка владельцем пока не выполнена.
