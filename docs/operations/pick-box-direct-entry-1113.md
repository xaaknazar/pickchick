# Pick Box - прямой вход и центральный подвес

## Статус

По отзыву владельца от 13 ноября убран дополнительный стартовый экран Pick Box.
Нажатие карточки в разделе «Игры» сразу открывает игровое поле. Первая короткая
подсказка остаётся внутри игры и исчезает после первого сброса. Обложка карточки
и все исходные изображения сохранены.

Владелец отдельно потребовал сначала показать результат в чате и дождаться его
утверждения. Эти изменения не загружались в TestFlight или Google Play. Номера
сборок не увеличивались. Следующий тестовый выпуск - только после подтверждения.

Верёвка теперь крепится по центру игрового поля, ниже всех надписей и кнопок.
Сообщения о попадании и серии используют одну область над полем; сообщение
нового этапа временно заменяет строку цели. Они не закрывают коробки и верёвку.
Настройки звука и вибрации доступны в паузе и результате.

## Доказательство

- 23 адресных теста Pick Box PASS. TypeScript, адресный ESLint и production
  web export PASS. Физика, счёт, локальный ключ рекорда и звуки не менялись.
- Семь тестов пульта проекта PASS после обновления записи Pick Box.
- Проверен реальный путь «Игры» - карточка Pick Box - игровое поле: дополнительной
  кнопки запуска нет. Первый сброс дал одну коробку; X открыл паузу. Начало отсчёта
  продолжения подтверждено. После перезагрузки сразу открылась новая попытка,
  рекорд 1 сохранился.
- Браузерные размеры 320x568, 393x852, 768x1024 и 844x390: горизонтального
  переполнения нет, точка подвеса по центру поля с погрешностью менее 0,01 px
  после завершения перестроения. Верхняя граница крепления ниже HUD.
- Ошибок страницы в финальном прогоне нет. Старый браузерный регрессионный
  сценарий обновлён для прямого входа; сам Python/Playwright-прогон не запускался,
  живая проверка выполнена через разрешённое управление браузером.
- Снимки для утверждения: [первый вход 393](pick-box-1112/direct-entry-393.png),
  [игра после первого попадания 320](pick-box-1112/direct-playing-320.png).
  Это реальный локальный web-предпросмотр React Native, не снимки новой сборки
  на физическом iPhone. Нативная и физическая приёмка этой правки ещё не выполнена.

## Откат

Изменения пока не распространялись. Можно вернуть экран и геометрию из
4c6e18e9 без миграции данных. Уже доступные тестовые пакеты не изменены.
