# iPad-киоск: редизайн 13 октября - внедрение

Задание: [docs/design/kiosk-redesign-2026-10-13/](../design/kiosk-redesign-2026-10-13/README.md).
Ветка `codex/kiosk-redesign-1013` от `origin/codex/shared-development`. Экран Kaspi QR,
ожидание и ошибки оплаты, диалоги, номер заказа и «Заказ готов» не менялись.
API, контракты и бизнес-логика контроллера не менялись; изменён только порядок экранов.

## Что сделано

**Старт** (`WelcomeContent.tsx`, `SaluteButton.tsx`, `Language.tsx` `surface="start"`):
стеклянный выбор языка, новый чип «Оплата через Kaspi QR», кнопка «СДЕЛАТЬ ЗАКАЗ» точно
по утверждённому макету (вариант «burst» в `Main.dc.html` дизайн-проекта): 140 пт, надпись
Montserrat 900 58, разрядка .04em, свечение 0 16 48 rgba(255,105,0,.45), без стрелки;
«Салют» с циклом 2,8 с - пружинка (ease-out), блик (ease-in-out, 6-50 %) и 14 частиц из
макета с теми же точками старта, направлениями разлёта, цветами и размерами (кружки 16,
звёзды 22): появление .3 → 1 на 4-8 %, разлёт к 70 % (масштаб .4), затухание 55-70 %,
cubic-bezier(.15,.7,.3,1). Только transform/opacity на native driver; при «уменьшить
движение» всё статично, частиц нет. Остальное на старте как было. Кадры 8/25/40/60 %
совпадают с макетом: [start-cta-vs-mock-1024.webp](images/kiosk-redesign-2026-10-13/start-cta-vs-mock-1024.webp).

**«Как будете есть?»**: применён `mode-title.diff` - заголовок в одну строку на RU/KZ/EN,
обе карточки одной высоты.

**Меню - бенто** (`MenuScreen.tsx`, `Header`, `DiningSwitch`, `Language` `tone="glass"`,
`CategoryRail`, `MenuGrid`, `Billboard` (хит раздела), `ProductCard`, `Badge`, `CartBar`,
`ScreenSurface tone="redesign"`, логика `menu-presentation.ts`):

- колонка разделов, хит раздела на всю ширину (Master Combo, Фингер Дуо, 25 фингерсов,
  Бургер, Лимонад; если хит на стопе - первая позиция раздела), сетка по числу позиций
  N = 3 / 4 / ≥5 по правилам задания, ряды в `fr`; не поместилось - раздел прокручивается;
- хиты и ярлыки (ХИТ, НОВИНКА, ОСТРОЕ, СВОЙ РЕЦЕПТ) заданы по id в `menu-presentation.ts`:
  в каталоге нет флагов для них;
- фото `assets/v3/photos` подрезаны по белым полям воспроизводимо
  (`scripts/kiosk/trim-photo-margins.py`, `trim-provenance.json`);
- стеклянная нижняя панель «Оформить заказ»: неактивна при пустой корзине; сводка
  (фото и сумма) открывает прежнюю страницу корзины для правки количества.

**Умные допы** (`UpsellScreen`, `smartUpsell.ts`, `UpsellHeader`, `StepPills`, `UpsellHero`,
`UpsellTile`, `UpsellSection`, `UpsellBoard`, `UpsellFooter`, `RadialBackdrop`):

- путь: «Оформить заказ» → всегда допы → «К оплате» / «Без допов» → сразу существующая
  оплата: при единственном способе Kaspi QR - экран QR (`beginPayment('kaspi')`), иначе
  прежний экран выбора способа. Страница «Ваш заказ» убрана из пути, но доступна по
  «В заказе: …» для правки; позиции на стопе показываются на допах и блокируют оплату;
- подбор: фингерсы без бургера → «Добавьте бургер» (К ФИНГЕРСАМ); бургер без фингерсов →
  «Добавьте фингерсы» (К БУРГЕРУ); есть оба → лимонад крупно; нет ни того ни другого →
  фингерсы с ярлыком ХИТ (решение по умолчанию, подтвердить);
- всегда: соусы (Фирменный, Острый; **Сырного нет в каталоге - плитка не показывается**,
  появится сама, когда позиция будет заведена), напитки (Лимонад, Холодный чай, Coca-Cola);
  уже бывшее в корзине не предлагается, добавленное здесь - зелёная рамка и галочка;
- «Назад» с экрана выбора способа оплаты ведёт на допы.

## Отличия и открытые вопросы

1. Кнопка «СДЕЛАТЬ ЗАКАЗ» по решению владельца приведена к макету (размер надписи,
   свечение, траектории частиц, кривые анимации); на 820 и 744 всё масштабируется через `px`
   (кегль 46 при минимальном масштабе .8).
2. В web-сборке на 744 казахский заголовок «Как будете есть?» обрезается многоточием (web не
   умеет уменьшать шрифт по ширине); на iPad шрифт уменьшается и заголовок виден целиком.
3. Без сырного соуса ряд соусов из двух карточек показан широкими карточками.
4. Названия позиций - как в каталоге («Бургер, 1 шт», «Фирменный лимонад 0.5 л»), короче
   в макете; длинные названия уменьшаются, не обрезаются.
5. Карусель «7+1» больше не показывается в меню (её нет в утверждённых макетах).
6. Хит раздела и ярлыки - по id; для настройки из бэк-офиса нужны поля каталога
   (`featured`, `badge`) - отдельная задача.
7. По прямому разрешению владельца включена ветка `codex/kiosk-design-demo`
   (`114d5555`): скрытый демо-режим и надпись KZ → RU → EN каждые 2,4 с
   перенесены в `SaluteButton`. Сохранены размер 58 pt, свечение, геометрия и
   частицы нового макета. Выбор языка останавливает смену надписи; при Reduce
   Motion надпись статична. Демо использует изолированный транспорт в памяти.
