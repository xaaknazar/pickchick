# Этап «На сборке» в приложении: список заданий при приёме на кухню

9 ноября 2026. Подготовка к демонстрации; ничего не установлено.

## Проблема

В режиме «целый чек» станция приготовления одним действием переводит свои задания
в `done`, а сборка завершает свои задания вместе с готовностью заказа. Облако узнаёт
о задании только из `edge.task_changed`, поэтому задания станций, которые ещё не
начинали работу, ему неизвестны. `kitchenStage='assembly'` требовал задания сборки
в `in_progress`/`done`, что в этом режиме совпадает с `ready`. Итог: приложение
показывало «Готовится» до «Можно забирать», этап «На сборке» не появлялся.

## Изменение

- Транспорт: у `edge.fulfillment_accepted` необязательное поле `tasks`
  (`taskId`, `stationId`, 1-100 строк). На других событиях поле запрещено.
- Касса: `EdgeFulfillment(pool, { reportTaskList: true })` добавляет список при приёме.
  Воркер включает это только при `FULFILLMENT_TRANSPORT_TASK_LIST=1`
  (`infra/windows/native-fulfillment-worker.mjs`), по умолчанию `0` - поведение прежнее.
- Облако: получив список, записывает каждое задание как `queued` версии 1 в
  `cloud_fulfillment_observed_tasks` и `cloud_fulfillment_task_versions`. Повтор и
  обратный порядок событий сходятся; другая станция того же задания - `CONFLICT`.
  Версия 1 бывает только у такого списка (`task_changed` начинается с 2), поэтому
  она же отмечает, что список заданий заказа полный.
- Вид заказа: `assembly`, если задания сборки начаты (прежнее правило) или список
  полный и все задания других станций `done`. Без SELECT на
  `cloud_fulfillment_task_versions` остаётся прежнее правило; право добавлено в
  `customerCheckoutGrants`.

Миграций нет. Деньги, номера, кухня и табло не меняются.

## Порядок установки

1. Облако: выпуск API с этим кодом и повторное применение checkout grants
   (иначе работает прежнее правило). Старая касса поле не присылает - совместимо.
2. Только потом касса: пакет Windows с этим кодом и `FULFILLMENT_TRANSPORT_TASK_LIST=1`
   в окружении воркера fulfillment. Касса с флагом при старом облаке получила бы отказ
   строгой схемы и остановила очередь, поэтому флаг включается последним.
3. Проверка: заказ из приложения, «Готово - на сборку» на всех станциях - в приложении
   «На сборке»; «Заказ собран» - «Можно забирать».
