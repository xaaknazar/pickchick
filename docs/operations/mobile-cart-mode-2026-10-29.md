# Способ получения над суммой быстрой оплаты

По двум скриншотам владельца от 29 октября 2026 в CartShortcut над суммой добавлена
светло-серая подпись текущего способа получения с иконкой из корзины:
`bag-handle-outline` для «С собой», `restaurant-outline` для «В зале».
Источник - `model.diningMode`, переводы существующие RU/KK/EN. Подпись также
добавлена в доступное имя кнопки. Сумма, жест оплаты, фотографии и стеклянный фон
сохранены. На экране уже 360 pt для длинной подписи показываются максимум две
фотографии, чтобы «Мейрамханада» помещалось вместе с иконкой. Выдуманное время
приготовления не добавлялось. Подпись исчезает вместе с суммой при движении ручки.

База: `528ea695` (shared). Ветка: `codex/mobile-cart-mode-1029`.
Предыдущий собственный резерв `mobile-appstore-clean-1029` завершён штатно:
его checkpoint `635fd3aa` уже включён PR293 в shared. Чужие активные задачи
не закрывались. Заняты только CartShortcut, его свободный browser_cart_shortcut
и этот протокол. Параллельная вибрация mobile-feedback-1029 не изменялась.

## Проверено локально

- Frozen offline install с pnpm 11.19.0; mobile dependency build, TypeScript,
  ESLint, Prettier и diff-check.
- 557 Node mobile + 59 Python тестов прошли. Первый Node-прогон не имел
  собранного catalog-pricing; после сборки тестовой зависимости повтор зелёный.
- browser_cart_shortcut: три вкладки, 320x568, 393x852, 768x1024, 852x393;
  подпись над суммой, переключение режима, сохранение после reload, нажатия по
  фото/цене/подписи открывают корзину. Перед координатным касанием тест теперь
  ждёт исчезновения перекрывающей шторки через фактический hit target.
- Отдельная изолированная проверка customer-auth export: оба режима RU/KK/EN
  на 320x568 и 393x852 с несколькими фото; подпись помещается и находится над
  суммой, доступное имя соответствует режиму, запросов checkout нет.
- browser_slide_to_pay B/I/L/Q: один тестовый счёт на завершённый свайп,
  локализованные подсказки, положение над вкладками, сигналы вибрации.
  Ответы банка и API исключительно локальные фикстуры, внешняя сеть блокируется.

Скриншоты - web export в Chromium, не физический iPhone и не native Simulator.
Симулятор и iOS-выпуск заняты параллельной задачей; в этом этапе не запускались.
Визуальные снимки локально: `.local/cart-mode-preview/` и `.local/cart-shortcut/screens/`.
