# Киоск 24 - обновление с сохранением привязки

Владелец 16.11 разрешил сборку и установку по кабелю поверх прежнего киоска,
а также передачу `apps/kiosk/app.json` и резерва `@release/ios` этой задаче.
Приложение для гостей и магазины не входят в этот выпуск.

На iPad подтверждена версия 0.1.0 (23). Она собрана 15.10 из
`13009f8d98aa74bae3df5d351d962d4be3664cf4`, до добавления поля кода сотрудника.
Владелец сообщил, что форма ввода кода не открывается. Серверный проверяющий
ключ установлен отдельно; успешный ввод на iPad пока не подтверждён.

Кандидат основан на `0400b87fde483b453be1a20c21402ea7720a311e`; в приложении меняется
только номер сборки с 23 на 24. Версия 0.1.0, Bundle ID `kz.pickchick.kiosk`,
Apple Team `DAJTP6MC3Q` и ключи SecureStore сохраняются. Сброс данных,
удаление приложения и новая привязка не разрешены и не выполняются.

Для архива используется явный профиль `kiosk-production` с API
`https://api.pickchick.kz`. Владелец уточнил: «фотопринтер позже настроим».
Инструмент выпуска получил явный вариант `--kiosk-photo-disabled`, несовместимый
с `--kiosk-photo-url`. Он закрепляет проверяемый несетевой маркер
`disabled:pickchick-photo-printing-v1` вместо адреса. Прежний `approvedEndpoint`
отвергает его: печать и новая привязка принтера недоступны, сохранённые данные
SecureStore не удаляются. Код приложения и прежние правила HTTPS не меняются.
Пропущенный адрес без явного отключения по-прежнему останавливает выпуск.
Для дальнейшего включения печати потребуется сборка с подтверждённым HTTPS origin.
Apple review demo и Mac photo preview не включаются. Приватные настройки,
PIN и данные устройства не публикуются.

До установки требуются зелёная Foundation CI точного исходника, проверенный
Release archive, прежние идентификаторы подписи и Keychain, разрешённый iPad
в профиле и проверка закреплённых адресов в JS bundle. Установка выполняется
поверх существующего приложения. После неё проверяются номер сборки,
сохранённое устройство в облаке и открытие меню сотрудника; код вводит владелец.
Заказы, оплату и задания печати эта проверка не создаёт.

Подготовка: 286 kiosk tests, 9 kiosk release tests, TypeScript, ESLint,
prebuild, CocoaPods и release doctor прошли до добавления явного отключения печати.
Правка инструмента выпуска проходит отдельные проверки и CI нового исходника.
На подключённом по кабелю iPad прочитана версия 23; прежний профиль содержит
это устройство, не истёк, Bundle ID и Apple Team совпадают. Приватные идентификаторы
устройства и профиль не публикуются.

Состояние на момент подготовки: новая сборка ещё не установлена. Подтверждения
архива, CI, установки и физической приёмки будут добавлены отдельно.
