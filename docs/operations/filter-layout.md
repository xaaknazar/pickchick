# Фильтры бэк-офиса и выбор должности

## 12 октября 2026: подготовлено, установка ожидается

По снимкам владельца выровнены панели периода, кассовой смены и обновления
на Главной и в Заказах. Общая панель сохраняет те же фильтры и команды.
У периода и смены одинаковая высота элементов и одна линия подписей;
пояснение выбранной смены вынесено отдельной строкой. На узком экране
периоды прокручиваются внутри панели, без горизонтального переполнения страницы.

В кадровом разделе вместо текстового month-поля, которое Safari показывал
без календаря, используются списки месяцев и годов. Ряд День/Неделя/Месяц,
Дата и Добавить смену выровнен. Должность на смене выбирается из списка:
Управляющий, Кассир, Повар, Сборщик, а также сохранённые должности графика.
При редактировании нестандартное прежнее значение сохраняется в списке.
Новая смена требует выбора должности. Ставки, права, расчёт и аудит не изменены.

## Стоп-лист: отдельная незавершённая зависимость

Проверка VPS на чтение 12 октября: API `f01cb45f`, schema052;
`BACKOFFICE_REMOTE_STOPS_ENABLED=false`. Обмен с кассой свежий, protocol4
содержит stop_states. Это подтверждает обмен, но не готовность кассы применять
удалённые команды. Кнопки уже реализованы и скрываются штатным readiness gate.

Владелец подтвердил SSH пользователя Windows «Админ» и доверенный fingerprint.
Переданные пути ключа и Paramiko относятся к другому Mac `/Users/xaknazar`;
на финансовом Mac этих файлов нет. Нужны актуальный IPv4 и добавление собственного
публичного ключа через существующий доверенный доступ. Приватный ключ не переносим.

Перед изменением кассы зарезервировать `@windows/cashier`, проверить fingerprint,
версию edge, schema/ACL, флаги, совпадение меню и готовность команд. Старый оператор
`continue-unified-menu.py` закреплён за cloud051 и не подходит вслепую к schema052.
Cloud-kitchen/новый stop-channel разрабатывается отдельной задачей: её резерв и
неустановленные миграции не обходить. Флаги API и Windows в этой UI-задаче не меняли;
удалённое управление стопами пока не объявляется установленным или принятым.
