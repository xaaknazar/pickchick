# Исправление установочного пакета кухни 21.10.2026

При разрешённом обновлении кухни из `59f0c0d` новый контейнер завершился до
готовности. Охраняемый установщик восстановил прежнюю кухню `5b6f846` и её
настройки; соседние сервисы не изменялись. Изолированный запуск пакета без
сети подтвердил причину: `server.mjs` импортирует `cloud.mjs`, но сборщик
не включал этот файл в дистрибутив.

В список пакета добавлен `infra/kitchen-portal/cloud.mjs`. Регрессионная
проверка собирает отдельный пакет вне исходной рабочей копии, сверяет хеши,
импортирует сервер только из пакета, запускает его на loopback и проверяет
health. Рабочая база, касса и банк в проверке не используются. Тест включён
в существующий набор CI `tests/kitchen-portal/*.test.mjs`.

Повторный выпуск допускается только из нового опубликованного SHA после
полной Foundation CI; каталог неудавшейся попытки сохраняется. Результат
установки записывается отдельно после фактической проверки.
