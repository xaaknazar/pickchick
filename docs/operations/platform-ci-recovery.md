## Исправления

- Сервер кухни отдаёт demo.js и ticket-view.js, импортируемые app.js. До правки
  новая проверка графа модулей воспроизвела 404 ticket-view.js, после прошла.
- Healthcheck портала использует node:http с правильным Host, читает origin
  из защищённого config. На VPS старый fetch действительно возвращал 403.
  Отключённая касса не выдаётся за падение самого процесса портала.
- Устаревшая проверка RUN заменена проверкой переходов M27/M28 к событиям;
  проверка серверного отключения MAN/BLOCKS сохранена.
- Сгенерированный demo-dist исключён из lint/format, исходники проверяются.
- Выбранный вариант корзины применён после передачи задачи, см. журнал корзины.
- Добавлено узкое обновление существующего портала с проверкой baseline,
  manifest, конфигурации, lock, SHA, закрытых маршрутов и неизменности остальных
  контейнеров. Секреты и шлюз не перезаписываются; неопределённый Docker-результат
  оставляет блокировку, обычная ошибка восстанавливает прежний контейнер.
