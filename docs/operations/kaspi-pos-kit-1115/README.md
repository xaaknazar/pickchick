Изменение выбора первых28 строк исправляет чтение вспомогательного ledger, но
`infra/windows/update-runtime-head-028.ps1:232` по-прежнему принимает архив только
с ровно28 SQL-файлами. Штатный packager включает все29 миграций.

Кроме того, оператор028 принимает predecessor-record ступени025 и созданные ею XML.
Он не является оператором повторного перехода с уже установленного runtime028 на029.
Проверенные альтернативные операторы привязаны к своим историческим схемам;
поддерживаемого общего пути установки029 не найдено.

Нужен явный проверенный путь для полного029-кандидата от фактической установленной
версии: CI proof, свежая проверенная копия, maintenance lock, остановленные службы,
миграция, переключение программы, проверки конфигураций/соседей и штатный откат.
