# PickChick 0.2.0 (30)

Владелец 30 октября разрешил выпуск в существующую PickChick Internal.
В Apple проверена сборка29 со статусом «Тестируется»; выбран свободный номер30.
Версия0.2.0, Bundle ID kz.pickchick.app, прежняя подпись и storefront сохранены.

## Изменения

- Над ценой быстрой оплаты серым показаны «С собой» / «В зале» и значок из корзины.
- Страницы допов используют синюю палитру комбо. Светлый фон внутри исходных фотографий не удалялся.
- Начало жеста: Heavy; 16 делений в обе стороны: Medium; порог оплаты: Heavy.
- Сохранено исправление системных отступов Pick Man из PR294.
