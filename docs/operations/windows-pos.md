# PickChick POS для Windows

Этот документ отделяет устанавливаемый клиент от готовой кассы ресторана.
Целевое оборудование владельца - BX S6 Dual, Windows, маркировка i5 / 8/128.
Точная версия Windows и расположение действующего локального сервера iiko
уточняются. [Архитектурное решение](../architecture/adr/0008-windows-pos-delivery.md).

## Что входит в первую поставку

Самостоятельное настольное приложение с локальным интерфейсом и собственным
runtime. Оно устанавливается в Windows и не требует открытия сайта или браузера.
Интерфейс, стили и логотип находятся в пакете; соединение с интернетом для
их загрузки не используется.

Клиент обращается к подготовленному локальному edge. Проверяются настоящие
роль сотрудника, точка, терминал и срок доступа. Доступны существующее локальное
меню, расчёт, сохранение неоплаченного заказа, поиск, отмена и восстановление
неизвестного результата. Цены и состояния определяет edge PostgreSQL.

Полноценные продажи ещё не приняты: приём денег, ККМ, смены, печать, допуск
POS-заказа на кухню, комбо/модификаторы локального каталога требуют следующего
этапа. Этот установщик пока не заменяет работающую iiko на точке.

## Перед первым рабочим входом

Нужны подготовленные локальные PostgreSQL/edge, активное меню точки, открытый
приём неоплаченных заказов и приватная сессия сотрудника. Порядок настройки:
[локальные заказы](local-orders.md), [клиент кассира](pos-client.md).
Установщик интерфейса не создаёт себе серверные права и не содержит общих
паролей или тестовой сессии.

Приложение подключается только к loopback-порту подготовленного узла.
Отдельный edge в LAN потребует управляемого защищённого подключения на Windows;
публичный VPS и облачные web-экраны не являются заменой локального узла.
Сеть/сертификаты и Windows service должны быть установлены отдельным этапом.
Текущие процессы и данные iiko этим установщиком не изменяются.

Приватный файл сессии выбирается при входе. Он не передаётся в адресе сайта
или параметрах ярлыка. После завершения доступа нужен новый файл, выданный
оператором; автоматический бессрочный вход кассира пока не реализован.

## Что значит работа без интернета

| Ситуация                                        | Фактическое поведение                                                                                                                                         |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Интернет отключён, локальный edge и БД работают | Локальное меню, расчёт и сохранение неоплаченного заказа работают через локальный API                                                                         |
| Локальный узел недоступен                       | Новый заказ не подтверждается из кеша; интерфейс показывает отсутствие ответа                                                                                 |
| Ответ потерян после сохранения                  | Неизвестный запрос сохраняется; проверка использует прежние body и ключ                                                                                       |
| Программа закрыта и открыта снова               | Восстановление из прежнего профиля после подтверждённого входа того же сотрудника/терминала                                                                   |
| Интернет восстановился                          | Центральное подтверждение требует установленного и настроенного POS sync worker, обеих схем и защищённого соединения; сам EXE не выдаёт себя за синхронизацию |

Окончание очереди неоплаченных заказов не подтверждает оплату или получение
фискального чека. Автономность зарегистрированной ККМ проверяется отдельно
с её поставщиком. На кухню должны попадать только заказы с выполненными
доверенными предпосылками оплаты/чека.

## Установка и приёмка

Файл `PickChick-POS-Setup-0.1.0-x64.exe` устанавливает программу для текущего
пользователя Windows и создаёт ярлыки на рабочем столе и в меню «Пуск».
Node.js, npm и отдельный браузер для запуска клиента устанавливать не нужно.
Вариант `PickChick-POS-Portable-0.1.0-x64.exe` запускается без установки;
он использует тот же профиль, поэтому оба варианта одновременно не запускаются.
Установщик не содержит Authenticode-подписи; прохождение SmartScreen пока не
проверено. Не отключать системную защиту ради установки.

Без настроенного edge приложение покажет вход и отсутствие связи с локальным
узлом. Это ожидаемое ограничение поставки, а не готовый автономный сервер.
После настройки узла кассиру нужен выданный оператором приватный файл сессии;
общий пароль или универсальный вход в программу не вшиты.

Точные имена, SHA-256, исходный commit и выполненные проверки фиксируются
в протоколе поставки после сборки. Исполняемые файлы публикуются как release
assets, исходники и lockfiles сохраняются в Git. Приватные настройки,
сессии и данные заказов в дистрибутив не включаются.

Установку, первый запуск, обновление с сохранением журнала, перезапуск Windows
и физическое отключение WAN нужно проверить на отдельном рабочем месте до
переключения действующей кассы. Сборка EXE на Mac и тест Electron на Mac
не считаются проверкой исполнения на Windows.

Для полного запуска остаются:

1. Обследовать Windows/локальный сервер и установить управляемый edge/LAN.
2. Подключить реальное меню, доступ сотрудников и локальные кассовые смены.
3. Интегрировать банк, ККМ/печать и восстановление неизвестного результата.
4. Разрешать локальную кухню из edge-owned заказа после оплаты/чека.
5. Развернуть проверенный POS sync и пройти полную смену без WAN с восстановлением.

Полученные ранее модель моноблока и ОФД WOFD повторно запрашивать не требуется.
Версия/SDK ККМ, назначение двух касс и её разрешённый автономный режим пока
не подтверждены. [Зависимости запуска](launch-inputs.md) и
[реестр оборудования](restaurant-equipment.md) сохраняют канонические сведения.
