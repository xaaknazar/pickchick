## Подпись и попытки доставки 1.0.1 (38)

Используется штатный `scripts/mobile/ios_release.py`, `--feature-profile production`,
API `https://api.pickchick.kz`, прежний профиль и сертификат сборки 37. Ключи и пароли
остаются только на Mac. Архив и экспорт **PASS**, версия 1.0.1 (38),
`temporarySigningSettingsRestored=true`. Локальный выпуск:
`~/Library/Caches/PickChick/releases/mobile-glass-20261116-38-r3/`.

IPA: 134742758 байт, SHA-256
`6647ae70947165b9a44a7363ab9cf9fce194a672fb38daf1cbb1ad362747b923`.

Загрузка **не принята Apple**. Первую попытку остановил `Failed to Use Accounts`.
16.11 владелец вошёл в Xcode Settings -> Apple Accounts, вход подтверждён.
Повторный штатный upload дошёл до проверки Apple и завершился с кодом 70:

- `90062`: версия `1.0.1` должна быть выше уже одобренной `1.0.1`.
- `90186`: `Invalid Pre-Release Train`, версия `1.0.1` закрыта для новых сборок.

Владелец разрешил пересборку как `1.0.2 (38)` только для TestFlight;
это уточнение заменяет исходное требование сохранять `1.0.1`.
Архив, IPA и журнал ошибки сохранены локально; повторять тот же upload бессмысленно.
Предупреждения dSYM сторонних framework также записаны в локальном журнале;
причина отказа - закрытая версия, а не эти предупреждения.
Сессия браузерного App Store Connect тогда истекла; владелец повторно вошёл
до успешного назначения групп новой версии 1.0.2. Пароль/код в чат не запрашивались.

Первый архив собрался, но штатный guard остановил фазу из-за параллельного
добавления EAS keychain другого проекта. Чужая сборка не прерывалась; после её
завершения восстановлен исходный список. Попытка повторного использования кэша
в другом каталоге отклонена Xcode (путь Swift module cache); после удаления
только пересоздаваемого кэша выполнена успешная чистая сборка r3.
Ни одна из предварительных попыток не загружена.

[Машиночитаемые доказательства](mobile-testflight38/release-evidence.json).

На предварительной проверке в TestFlight последней была сборка 37, группы:
PickChick Internal - внутренняя, Testing - внешняя. Именно попытка 1.0.1 (38)
не была принята Apple; успешная доставка 1.0.2 (38) описана выше.
Ветка также обычным merge включила `0fbd095d` из cutover: согласованное удаление
стекла у категорий и запись об отложенных шторках. При этом слиянии код приложения
не изменился; сохранены обе записи статуса. Коммит объединения `423c7c8b`.

## Приёмка на iPhone

- iOS 26: настоящее Liquid Glass, плавное выделение, первое открытие «Игр» и «Заказов».
- Протяжка выбирает вкладку; для гостя «Заказы» открывают вход, подложка возвращается.
- «Понижение прозрачности» делает бар непрозрачным.
- Pick Box открывается напрямую, работает сброс, пауза, выход и сохранение рекорда.

Предыдущий Release 1.0.1 (38) для iPhone Simulator собран и установлен.
Визуальная проверка не подтверждена: тогда окна Mac были недоступны инструменту
управления (`cgWindowNotFound`). Симулятор выключен и ресурс возвращён задаче
mobile-feedback-1029. Новая маркетинговая версия 1.0.2 на симулятор не устанавливалась.

Браузерные проверки не подтверждают нативный эффект Liquid Glass или физическую приёмку.
Онлайн-пульт не публиковался: текущий разрешённый выпуск ограничен TestFlight.
