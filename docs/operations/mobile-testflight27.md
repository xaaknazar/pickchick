## Чек-лист владельца

- После X и полного закрытия приложения новый запуск показывает «Меню».
- Корзина открывается корзиной, без автоматического экрана оплаты.
- Явная повторная оплата показывает тот же заказ без второго счёта.
- Незакрытая оплата предлагается баннером, без автоматического выставления счёта.
- Закрытия из сборки 26 остаются закрытыми после обновления.
- Оплаченный в отсутствие приложения заказ появляется в счётчике «Заказы»;
  совпадающие оплаченные строки убираются из корзины.

Банковские состояния проверять только на изолированных фикстурах, без реального
счёта и платежа. iPhone/VoiceOver/Dynamic Type/Liquid Glass отдельно от браузера.
