# PickChick Kitchen 0.1.0 Preview для Windows

14 сентября 2026 опубликован [предпусковой установщик кухни](https://github.com/xaaknazar/pickchick/releases/tag/kitchen-v0.1.0-preview.1).
Изменения: [PR #51](https://github.com/xaaknazar/pickchick/pull/51), поверх Windows POS / PR #44.
Источник артефактов - чистый commit `73463c6a5bbd97efe6532b4233629c90632c7cf6`.
Этот протокол добавляется после упаковки и не изменяет проверенные EXE.

В release также входят `SHA256SUMS.txt`, `READ-ME-FIRST.txt`, `verification.json`
и `asset-manifest.json`. Размеры и серверные SHA-256 всех шести assets совпали
с локальными файлами до публикации. Бинарные файлы не включаются в Git history.

Клиент использует исходные `apps/kitchen` renderer/model/gateway, локальные шрифты
и изображения. Крупные кнопки переключают только назначенные станции; один kitchen
доступ может иметь prep + assembly. Выдача - действие assembly. Режим табло
сохранён. Журнал неизвестного результата не сбрасывается сменой станции.

Установщик для текущего пользователя создаёт ярлыки; отдельные браузер/Node/npm
для клиента не нужны. Фиксированный UI origin `http://127.0.0.1:4178/`, отдельный
профиль PickChickKitchen, single-instance, sandbox, без Node в renderer и внешней
навигации. При занятом порте клиент прекращает запуск, не открывает чужую страницу.
Для edge на кассовом моноблоке всё ещё нужен настроенный защищённый канал.

## Проверки

- 30 kitchen unit/model/gateway + 5 PostgreSQL/browser сценариев прошли; просмотрены
  1280×800 и 1920×1080, один обычный kitchen-вход, касания, prep/assembly/ready/handoff,
  табло, потерянный ответ и повтор без дублирования.
- В интеграционной ветке прошли 4 desktop security-теста и настоящий Electron
  lifecycle: secure context/Web Locks, вход, станции, табло, sandbox, отсутствие
  внешних запросов/навигации, запись неизвестной команды до POST, штатный restart,
  запрет восстановления другим сотрудником и точный повтор с одним fixture-эффектом.
- TypeScript, целевой ESLint/Prettier, ссылки документов и staged diff проверены.
- `dist:win` / `verify:win` прошли из чистого исходного коммита. Проверены 26 input
  hashes, 13 renderer assets, точная копия gateway, ASAR allowlist, AMD64 payload
  и security fuses. NSIS bootstrap имеет PE32; вложенное приложение - PE32+ AMD64.
- Для передачи установщиков прошли два Python-теста allowlist/путей/Host/hash;
  обе ссылки EXE проверены HTTP-чтением с Mac и исходными SHA-256.

Первый release-build в интеграционной ветке отказался от незакоммиченных ссылок
`node_modules`. Ignore исправлен для symlink-каталогов зависимостей; затем сборка
выполнена из чистого дерева. Проверка грязного дерева не отключалась.

## Что пока не подтверждено

Authenticode-подписи нет. Windows-исполнение, SmartScreen/Defender, touch,
установка/обновление/удаление, автозапуск, физический reboot/power loss и работа
служб на моноблоках ещё не приняты. Electron-проверка на Mac этого не заменяет.
Runtime-профиль использует существующий localStorage-журнал; fsync при внезапной
потере питания не заявляется. Бессрочный автоматический staff-вход не реализован.

Установщик не включает PostgreSQL, edge, credentials, реальные заказы или меню.
Банк/ККМ, денежные смены и допуск неоплаченного POS на кухню остаются отдельной
разработкой/приёмкой. [Размещение на двух Windows](../two-windows-workstations.md).

Владелец передал AnyDesk ID; запрос подключения к кассе отправлен. Подтверждение
на удалённом устройстве и фактические действия фиксируются отдельным протоколом
монтажа, когда подключение состоится. Приватные ID/адреса не включены в release.
