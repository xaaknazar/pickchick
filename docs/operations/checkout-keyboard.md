# Клавиатура комментария при оформлении

Исправление по обращению владельца от 2 октября 2026: поле комментария и
действие Kaspi перекрывались системной клавиатурой внутри нижнего листа.

## Поведение

При вводе комментария большой блок итога и оплаты заменяется компактной
кнопкой «Готово» высотой 48 pt. Она только закрывает клавиатуру. После закрытия
возвращаются прежние итог и действие оплаты; комментарий остаётся в черновике.
Системная клавиша Done тоже завершает ввод. Сам ввод не выставляет счёт.

OrderSheet передаёт Page смещение своего верхнего края относительно окна.
KeyboardAvoidingView учитывает это смещение; локальная координата уже включает
ручку листа, поэтому её 28 pt повторно не добавляются. Обычные футеры других
экранов не заменяются. Поле комментария, серверная котировка и платёжные
обработчики сохранены.

Применены UI/UX Pro Max (React Native: keyboard avoiding, системная клавиатура)
и Impeccable (адресная правка взаимодействия без редизайна). Независимое ревью
на GPT-6.1 Sol не нашло конкретных замечаний к реализации.

## Проверки и поставка

Mobile TypeScript, адресный ESLint, git diff --check прошли. Нативный XCUITest
проходит через preview-меню, товар, корзину и оформление без OTP/банка.
Он проверяет ввод, геометрию поля и «Готово» над системной клавиатурой,
отсутствие действия оплаты во время ввода, возврат футера и сохранение текста.
Проверка прошла на iPhone 17 Pro simulator iOS26.5, Release0.2.0(7):
`checkout-keyboard-smoke-5.xcresult` в приватном кеше Mac. Скриншоты с настоящей
системной клавиатурой сверены: поле целиком видно, футер не перекрывает его.
Первый сценарий обнаружил также отсутствие прокрутки поля: теперь ScrollView
после показа клавиатуры измеряет границы окна и поднимает поле только на
недостающую высоту. TypeScript, ESLint, форматирование и mobile Node/Python
(34 Python) проходят. Серверные операции не вызывались.

Подготовлена версия 0.2.0 (7); до завершения CI, подписи, загрузки и обработки
Apple на телефоне остаётся предыдущая сборка. Приёмка на физическом iPhone
и доставка комментария реальному кухонному заказу пока отдельно.
