# Исправления корзины и связи после TestFlight 24

По сообщению владельца 28.10 исправляются четыре проблемы: мигающее сообщение о связи,
слишком широкая корзина, уменьшающийся текст способа получения и неработающий обычный свайп.

## Изменения

- Оценка `isInternetReachable` больше не останавливает запросы при подключённом сетевом интерфейсе. Ответы API определяют связь с сервером; явное отсутствие интерфейса по-прежнему останавливает чтение. При возвращении приложения обновляется снимок сети.
- После транспортного отказа долгого запроса выполняется один немедленный GET без `after`. Успех не вызывает ложную вспышку offline; отказ подтверждает offline и включает прежний backoff. HTTP-отказы, rate limit, некорректные ответы и отмена при уходе в фон не обходятся. Для долгого запроса бюджет 35 секунд (сервер ждёт 20), для обычного GET 10 секунд. Платёжные команды не повторяются этим механизмом.
- Корзина по центру, максимум 320 pt и внешние отступы минимум 24 pt. Закрытая корзина сохраняет размер по содержимому.
- «В зале / С собой»: 17 pt, строка 24 pt, без автоматического уменьшения; длинная надпись переносится. Системный размер текста поддерживается, высота кнопки от 48 pt.
- Начало горизонтального движения запускает растяжение без обязательного удержания 250 мс. Это уточнение прежнего жеста по жалобе владельца. Вертикальное движение отделено, полный свайп по-прежнему подтверждается только после отпускания на 85% пути; отмена сбрасывает ручку. Гость открывает вход без заказа или счёта.

## Доказательства и ограничения

Два публичных GET к production: обычный ответ 0,18 с, long poll 20,16 с; оба enabled=true,
fresh=true, orderingOpen=true, часы 10:00-00:00 Asia/Almaty. Сервер не изменялся.
Это не воспроизведение радиосвязи конкретного iPhone владельца. Конфликт оценки сети с ответами API
и обрыв long poll покрываются управляемыми регрессиями.

Локально: 490 Node-тестов мобильного приложения, 59 Python-тестов, TypeScript и адресные lint/format прошли.
Браузерная корзина 393/320 прошла, включая повторные переключения текста 17 px. Все финансовые
ответы этих браузерных сценариев - изолированные фикстуры; production-мутаций нет.
Полный сценарий свайпа A-N (393/320, RU/KK/EN, reduced motion) прошёл, включая немедленное начало, ранний отпуск, единственную отправку в фикстуру и запрет повторов. Native iPhone Simulator выполняется. Физическая приёмка не выполнена.

Новый TestFlight пока не опубликован. API, миграции, флаги, касса, киоск и App Review не менялись.
Онлайн-пульт не опубликован: серверный выпуск остаётся отдельным решением владельца.
