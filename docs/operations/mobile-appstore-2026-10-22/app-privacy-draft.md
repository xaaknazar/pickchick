# App Privacy - подготовленная анкета 22.10.2026

22.10.2026 после отдельного согласия владельца опубликована в Apple.
Статус «Опубликовано» подтверждён в App Store Connect; приложение на проверку
не отправлялось. Имя файла сохранено как исходный рабочий документ анкеты.
Все 8 типов отмечены как связанные с пользователем, для функций приложения,
без отслеживания для сторонней рекламы. Состояние соответствует build21 storefront.

| Тип Apple                       | Фактические данные                                                      | Основание                                                                                         |
| ------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Имя                             | Имя/псевдоним профиля                                                   | packages/customer-identity/src/contracts.ts, CustomerPatchSchema                                  |
| Номер телефона                  | Вход, зашифрованный номер, lookup HMAC                                  | packages/customer-identity/src/index.ts                                                           |
| Платёжная информация            | Способ и статус оплаты заказа; реквизиты карты не вводятся в приложении | packages/commerce-core/src/customer-checkout.ts, services/api/src/customer-checkout-controller.ts |
| Другой пользовательский контент | Звёзды и текст отзыва о заказе                                          | apps/mobile/src/useCommerceFeedback.ts                                                            |
| ID пользователя                 | Идентификатор покупателя/аккаунта                                       | packages/customer-identity/src/contracts.ts                                                       |
| ID устройства                   | Идентификатор установки для авторизации и защиты                        | apps/mobile/src/customer-session.ts                                                               |
| История покупок                 | Состав, сумма и история заказов                                         | services/api/src/customer-checkout-controller.ts                                                  |
| Другие типы данных              | Необязательные дата рождения/пол, согласия, HMAC IP для защиты входа    | packages/customer-identity/src/contracts.ts, index.ts                                             |

Не заявлялись сбор GPS, адресной книги, пользовательских фото, здоровья,
рекламный IDFA, сторонний рекламный трекинг. Серверные push/7+1 и Pick Farm
выключены; будущие включения требуют повторной проверки декларации.

Владелец подтвердил публикацию анкеты в Apple. Опубликованную политику
нужно привести в соответствие с действующими сроками сессий (90 дней максимум,
30 дней без обновления) и необязательными полями профиля. Настоящая анкета не
заменяет юридическую проверку политики.
