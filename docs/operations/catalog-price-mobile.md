## Реализация

При `EXPO_PUBLIC_PUBLISHED_CATALOG=1` существующая проекция берёт версии,
ID, категории, модификаторы и цены мобильного канала из опубликованного BO.
Локальные фотографии сохраняются; изображения карточек и меню не заменялись.
Ошибка загрузки не переключает клиент на мокап. Параллельные bounded GET теперь
ожидают завершения обеих загрузок перед восстановлением после ошибки.

Сохранённая корзина `test:mockup-v0.3` восстанавливается из точного локального
снимка с прежними ценами, количеством и выбранными вариантами. Она сохраняет
старую версию при повторном запуске; текущая публикация не подменяет её снимок.
Клиент показывает сообщение о старом меню и предлагает «Обновить корзину».
Неизвестная версия не восстанавливается по сегодняшним ценам: показывается
сообщение о необходимости снова добавить блюда. Добавление рекомендаций
в устаревшую корзину блокируется, как обычное добавление блюда.

После явного обновления сохраняются количество и допустимые выбранные варианты,
используются текущие цены, недоступные строки удаляются с объяснением. Новый
пустой заказ привязывается к текущему снимку. Возврат приложения на экран
обновляет витрину, сохраняя прежний снимок непустой корзины до явного действия.
Существующий ответ `CATALOG_UPGRADE_REQUIRED` предлагает обновить приложение.

## Проверки

- 26 адресных Node-тестов: опубликованные цены/версии/модификаторы, старые и
  обновлённые суммы, повторный запуск, редактирование, рекомендации, checkout
  retry/cancellation; mapping ошибки обновления приложения.
- `@pickchick/mobile typecheck`, ESLint и Prettier затронутых TS/JS.
- Expo web export с `EXPO_PUBLIC_PUBLISHED_CATALOG=1`,
  `EXPO_PUBLIC_KASPI_CHECKOUT=1`, `EXPO_PUBLIC_CUSTOMER_AUTH=server`.
- `tests/mobile/browser_catalog_price_migration.py`: синтетический опубликованный
  снимок seed BO, mobile PickCombo 100 ₸, toast 25 ₸; размеры 393×852 и 430×932.
  Цена меню/карточки, локальная фотография, default drink/sauce, рекомендации,
  прежняя корзина 8 780 ₸ после двух запусков, явное обновление до 600 ₸,
  foreground новой версии, повторный запуск старого published-снимка,
  явное обновление до 800 ₸. Все финансовые команды запрещены fixture.

Браузерная команда: `python tests/mobile/browser_catalog_price_migration.py
<каталог Expo web export> <JSON синтетической публикации>`.
JSON получают из `packages/catalog-admin/dist/seed.js` (`mockupCatalogDraft`),
задают branch UUID, channel `mobile`, version 3, published_at, и mobile prices
`pick-combo:10000`, `toast:2500`. Тест сам поднимает локальный SPA-сервер.

PostgreSQL browser integration не запускалась в этой рабочей копии: Docker daemon
недоступен. Платежи, счета и заказы fixture не создаёт. Полная CI, публикация
серверного флага и новая нативная доставка остаются задачами root. Общие
project-status/roadmap заняты вторым Mac; эта подзадача их не перезаписывает.
