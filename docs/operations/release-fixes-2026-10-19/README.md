## Решения PM (по умолчанию; владелец может изменить)

1. Комбо недоступно, если остановлен фиксированный компонент или все варианты обязательной
   группы; остановленный вариант показывается «Нет в наличии»; связанные модификаторы
   (напитки, соусы) следуют стопу своего товара.
2. Попытка оплаты Kaspi, не отправленная в банк, истекает через 10 минут
   (`KASPI_REMOTE_PENDING_MAX_AGE_SECONDS`), денег не взято.
3. Возвраты Kaspi делает персонал в Kaspi Pay; PickChick регистрирует их командой «Зарегистрировать
   ручной возврат»; кнопка «Запросить возврат» скрыта, пока нет адаптера возвратов.
4. Мобильные продажи без фискального чека кодом не меняются; есть серверный выключатель
   `CUSTOMER_KASPI_SALES_ENABLED` (по умолчанию - как сейчас).
5. Клиенты берут адрес API и юридические ссылки из конфигурации сборки; production-сборки -
   `https://api.pickchick.kz`, staging - прежний nip.io.

## Стоп комбо на самой кассе (1.3 / 4.2 / 6.3, остаток)

Правило PM 1 работает в киоске, приложении и при допуске заказов киоска/приложения на кассе.
Продажа комбо кассиром на POS проверяет только стоп самого товара и стоп выбранного варианта
(`packages/local-orders/src/orders.ts`, `checkStops`). Чего не хватает:

- Меню кассы (`MenuSnapshotSchema`, `packages/contracts`) - строгая схема с контрольной суммой
  публикации; в нём нет связи «вариант -> товар» и состава комбо. Установленный edge
  (`services/edge`, `local-orders`) разбирает меню строго и новое поле не примет.
- Нужно: (1) необязательные поля в контракте, например `combo_component_variant_ids` у товара и
  `linked_variant_id` у варианта; (2) релиз кассы, который их принимает и проверяет в
  `checkStops` (и показывает в POS), не ломаясь на меню без них; (3) только после обновления
  кассы облако начинает их отправлять (`projectCatalogMenu`), например по серверному флагу,
  который владелец включает после установки кассы; (4) данные: «Связанный товар» у вариантов и
  `combo_components` у комбо в кабинете (в демо-каталоге состав комбо пуст).
- До этого кассир видит стоп товара в стоп-листе и не продаёт его в комбо вручную.
