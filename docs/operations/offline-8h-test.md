# 8 часов без интернета на точке: порядок проведения

Приёмка `launch-offline` (AC-15..18, [docs/04-roadmap.md](../04-roadmap.md)) на двух
моноблоках: касса (кассовый узел, PostgreSQL, POS) и кухня. Стенд
[offline-stand.md](offline-stand.md) уже проверил логику на одной машине; на точке
подтверждаем то, что стенд проверить не может: Windows, автозапуск, реальный роутер и LAN,
питание, сертификаты и локальные адреса без интернета, работу людей.

Это порядок проведения, не отчёт. Результат заносится в протокол (раздел 7) и
`docs/operations/deployments/` после теста.

## 1. Условия допуска (до назначения даты)

Без любого пункта тест не начинать.

1. На кассе установлен выпуск кассового узла, в котором есть `GET edge/v1/cloud-link`, и роли
   Edge выдано право `cloudLink` (`infra/windows/edge-runtime-grants.mjs`, флаг
   `cloudLink: true`, выполняет установщик выпуска). Касса v2 (POS) того же выпуска.
   Проверка: при выдернутом кабеле интернета вверху кассы жёлтое «Нет интернета · касса
   работает». Если касса показывает «Локальная сеть» - право не выдано, тест не начинать.
2. Кухонный моноблок работает через **локальную кухню** (`PickChickKitchen`,
   `install-kitchen-lan.ps1`), а не через внешний портал: портал через VPS без интернета не
   работает. Проверка: вверху кухни «Связь с локальным узлом».
3. Службы кассы установлены и запускаются сами: `PickChickEdge`,
   `PickChickFulfillmentWorker`, `PickChickPosSync`, `PickChickMenuSyncWorker` (режим
   `apply`), `PickChickKitchenLink` если используется. Перезагрузка Windows поднимает их без
   входа оператора (проверить заранее, отдельно от теста).
4. Свежая проверенная копия БД кассы (`backup-native-edge.ps1`) сделана в день теста
   и лежит не только на диске кассы.
5. ИБП: касса, роутер и коммутатор на ИБП. Адреса кассы и кухни закреплены (резервация DHCP).
6. Касса работает в режиме `unpaid_service` (ADR-0010): банк, терминал и ККМ в этом тесте не
   участвуют, денег через систему не проходит. Если на точке уже подключена реальная оплата,
   этот документ нужно дополнить до теста.
7. Назначены: ведущий теста (протокол и время), кассир, повар/сборщик, менеджер в кабинете
   **вне точки** со своим мобильным интернетом, контакт разработчика на связи.
8. Окно: 8 часов подряд в рабочее время с реальными или тестовыми заказами кассы; гостям
   заранее объяснено, что заказы через приложение и киоск в это время не принимаются.

## 2. Что выключать

- **Интернет (WAN)**: вынуть кабель провайдера из порта WAN роутера (или отключить порт
  провайдера в его кабинете). Роутер, коммутатор, Wi-Fi и питание не трогать. Если есть
  резервный LTE-канал, отключить и его, иначе это не тест без интернета.
- **Локальная сеть до кухни (LAN, короткий тест в середине)**: вынуть Ethernet из кухонного
  моноблока (или выключить на нём Wi-Fi) на 2 минуты. Кассу от сети не отключать.
- **Перезагрузка кассы (в середине)**: штатная перезагрузка Windows на кассе.

## 3. Перед началом (за 30 минут)

Записать в протокол время и результат каждого пункта.

1. Касса: вверху «Локальная сеть» (зелёная точка). Смена открыта.
2. Кухня: «Связь с локальным узлом», станции приготовления и сборки открываются.
3. Кабинет (менеджер вне точки): касса на связи, стоп-лист совпадает с кассой.
4. Пробный заказ кассы с модификатором и комбо проходит кухню до выдачи; он виден в кабинете.
5. Очереди кассы пусты (раздел 6, запрос 1): все счётчики 0.
6. Если включён пилот приложения: тестовый заказ из приложения оплачен и выдан; второй
   тестовый заказ оформить и **оплатить за 1-2 минуты до отключения** («в пути», AC-18).

## 4. Ход теста

| Время      | Действие                                                                                      | Ожидаемо                                                                                                                                                                              | Записать                                                        |
| ---------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| T0         | Вынуть кабель интернета                                                                       | -                                                                                                                                                                                     | точное время                                                    |
| T0 + 1 мин | Смотреть на кассу и кухню                                                                     | Касса: жёлтое «Нет интернета · касса работает» (не позднее ~40 с); кухня: «Связь с локальным узлом»; кабинет: касса не на связи; приложение и киоск: новые заказы не принимаются      | время появления надписи                                         |
| T0 + 5 мин | 3-5 заказов кассы (с модификатором, комбо, одна отмена)                                       | Касса принимает, кухня получает, номера выдачи без повторов                                                                                                                           | номера заказов                                                  |
| каждый час | 3-5 заказов, полный цикл кухни (начать, готово, выдано), стоп и снятие стопа позиции на кассе | Всё работает; остановленную позицию касса не продаёт                                                                                                                                  | число заказов, надписи кассы и кухни, размер очереди (запрос 1) |
| T0 + 2 ч   | **LAN-тест**: вынуть сеть кухонного моноблока на 2 минуты, на кассе продолжать продавать      | Кухня: «Нет актуального подтверждения связи»; касса продаёт, вверху остаётся жёлтое «Нет интернета» (не красное); после возврата кухня видит все заказы                               | время, номера заказов за 2 минуты                               |
| T0 + 3 ч   | Менеджер вне точки ставит стоп позиции в кабинете                                             | Команда ждёт кассу; через 2 минуты без связи истекает (это норма)                                                                                                                     | время, статус в кабинете                                        |
| T0 + 4 ч   | Закрыть смену с пересчётом наличных и открыть новую                                           | Закрывается без интернета; номера выдачи начинаются заново                                                                                                                            | суммы смены                                                     |
| T0 + 5 ч   | Перезагрузить кассу (Windows)                                                                 | Службы поднимаются сами; касса открывается, заказы и смена на месте; кухня переподключается сама                                                                                      | время до первой продажи после перезагрузки                      |
| T0 + 8 ч   | Вставить кабель интернета                                                                     | Касса: жёлтая надпись пропадает за ~1 минуту; очереди уменьшаются до 0 (запрос 1 каждые 2 минуты); кабинет видит все заказы, смены и стопы; приложение и киоск снова принимают заказы | время пропадания надписи, время до пустой очереди               |

Во время теста не перезапускать службы и не править базу без разработчика. Если кассир
видит красное «Нет связи с кассой» - это не интернет, а сама касса: перейти к разделу 5.

## 5. Когда остановить тест

Вернуть интернет и записать причину, если:

- заказ, принятый кассой, пропал или появился дважды;
- касса не может продавать дольше 5 минут или красное «Нет связи с кассой» не проходит;
- кухня не получает заказы кассы по LAN дольше 5 минут при работающей сети;
- кухня показывает уже выданный заказ как новый, номера выдачи повторяются у живых заказов;
- в очереди растёт число ошибок (раздел 6, запрос 2) после возврата интернета.

## 6. Запросы для ведущего (только чтение, владелец БД на кассе)

Выполнять в `psql` к `pickchick_edge` от владельца базы. Ничего не изменять.

```sql
-- 1. Что ещё не отправлено в облако
SELECT
  (SELECT count(*) FROM outbox_events WHERE acknowledged_at IS NULL) AS pos_orders,
  (SELECT count(*) FROM fulfillment_outbox WHERE acknowledged_at IS NULL) AS kitchen,
  (SELECT count(*) FROM cashier_report_outbox WHERE acknowledged_at IS NULL) AS reports;

-- 2. Состояние каналов
SELECT last_success_at, last_error FROM fulfillment_transport_state;
SELECT failure_count, last_error, retry_after FROM pos_order_sync_state;
SELECT failure_count, last_error, dead_lettered_at FROM pos_kitchen_sync_state;
SELECT count(*) AS parked FROM fulfillment_transport_reverse_failures WHERE resolved_at IS NULL;
```

После возврата интернета очереди (запрос 1) должны дойти до 0. По стенду: порядка 6 событий
в секунду при хорошей связи, то есть 8 часов работы досылаются десятки минут; статусы кухни
заказов приложения и киоска могут догонять до ~5 минут. `dead_lettered_at` не пустой или
`last_error` не исчезает дольше 10 минут после возврата связи - зафиксировать и сообщить
разработчику, вручную ничего не пропускать.

## 7. Протокол

| Пункт                                             | Ожидаемо                                       | Факт | Время |
| ------------------------------------------------- | ---------------------------------------------- | ---- | ----- |
| Надпись «Нет интернета» на кассе после отключения | до ~40 с                                       |      |       |
| Надпись на кухне без интернета                    | «Связь с локальным узлом»                      |      |       |
| Приложение и киоск без интернета                  | новые заказы не принимаются                    |      |       |
| Заказов кассы за 8 часов                          | все приняты кухней и выданы или отменены       |      |       |
| LAN-тест: надпись на кухне / касса                | «Нет актуального подтверждения связи» / жёлтое |      |       |
| Закрытие смены без интернета                      | закрыта, суммы верны                           |      |       |
| Перезагрузка кассы: время до первой продажи       |                                                |      |       |
| После возврата: надпись пропала                   | до ~1 мин                                      |      |       |
| После возврата: очередь пуста                     | время                                          |      |       |
| Кабинет: заказы, смены, стопы совпадают с кассой  | да                                             |      |       |
| Заказ приложения «в пути»: принят кухней один раз | да                                             |      |       |
| Потерянные или задвоенные заказы                  | 0                                              |      |       |

Подписи: ведущий, кассир, повар, менеджер.

## 8. Что этот тест не проверяет

Оплату картой/Kaspi на терминале, фискальные чеки и автономный режим ККМ (их на точке пока
нет), Яндекс, бонусы со списанием (без центра списание запрещено по
[03-offline-and-reliability.md](../03-offline-and-reliability.md)). Восстановление БД кассы
из копии проверяется отдельно по [edge-restore.md](edge-restore.md) и на стенде
(`edge_restore`): после восстановления очередь кухонных событий кассы может встать на
заказе, который был в работе в момент копии (известное ограничение).
