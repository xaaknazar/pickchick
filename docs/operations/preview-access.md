## Вход на служебные экраны

Откройте нужную ссылку, вставьте ключ **именно её роли** в поле «Ключ доступа»
и нажмите «Открыть рабочий экран». Ключ хранится в sessionStorage текущей вкладки.
Ключ табло не позволяет открыть кухню. При закрытии вкладки/истечении срока
понадобится повторный вход; истёкший ключ оператор перевыпускает через
[штатный trusted CLI](staging-test-flow.md#выдача-доступа-к-кухням-табло-управляющему).

Для владельца подготовлен отдельный локальный файл `.local/roadmap-audit/TEST-доступы.md`
с четырьмя проверенными ключами и точным сроком действия по Алматы.
Файл имеет права 0600, исключён из Git и публичной раздачи; ключи нельзя переносить
в URL. В этот документ секреты намеренно не включаются.

## Увидеть движение одного заказа

1. Откройте киоск, обе кухни и табло в отдельных вкладках; выполните вход на
   служебных экранах. Пустая очередь после выдачи прошлых TEST-заказов нормальна.
2. В киоске нажмите «НАЧАТЬ →», выберите режим, блюдо, добавьте в корзину,
   затем «Оформить заказ →» и «Продолжить →».
3. Нажмите «Рассчитать тестовый заказ», затем «Создать тестовый заказ →».
   Запомните номер `T-…` и выберите **«Тест: подтвердить оплату»**.
4. На кухне A отметьте обязательные задания «Готово». На кухне B после их
   выполнения нажмите «Заказ собран». Этот же номер появится в «Готово» на табло.
5. Подтвердите выдачу на кухне B. Номер исчезнет с табло и останется в истории.

Мобильный вариант: установить PickChick **0.1.0 (4)** через TestFlight и выполнить
[сценарий тестового заказа](mobile-beta-0.1.0.md). Заказы mobile и киоска попадают
в одну TEST-очередь. Состояние настоящей оплаты эти кнопки не проверяют.

## Что означает бэк-офис

`/manager` сейчас обслуживает только TEST-заказы и их счётчики. Ссылки на
номенклатуру, остатки, финансы, сотрудников, игры и CRM открывают подписанные
макеты будущих разделов. Это не работающий склад, бухгалтерия или аналитика
реальных продаж. [Матрица готовности](../audits/2026-09-07-roadmap.md).

Сами экраны доступны в браузере; установка на физические iPad, Windows,
кухонные устройства и LED-плеер, автозапуск и работа через LAN — отдельная приёмка.
Проверка доступа выполнена без создания заказов: четыре входа по ролям, киоск
и макет B02 открылись, ошибок JavaScript нет.
