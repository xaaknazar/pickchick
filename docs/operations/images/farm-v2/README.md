# PICK FARM v2 - снимки

Web export в Chromium, изолированный HTTP-fixture с настоящим движком, задержка сети
600 мс. Это не нативная приёмка: pinch, удержание и FPS на телефоне не проверялись.

- `before-open.jpg`, `before-zoom.jpg` - версия `239148b`: стартовый обзор с полосами
  без луга и приближение кнопкой помощи.
- `after-same-garden.jpg` - тот же сад (24 грядки, 2 яблони) при первом открытии v2.
- `after-open.jpg` - стартовый вид v2: камера показывает сад, трава из одной клетки закрывает экран.
- `after-overview.jpg` - «Весь участок»: поле 32x32 и дом.
- `harvest-in-flight.jpg`, `harvest-fly.jpg` - сбор до ответа сервера: растение
  исчезло, монеты летят в счётчик, сумма ещё прежняя (точка - сохранение).
- `watering-can.jpg` - полив касанием, влажная земля темнее.
- `seed-bar-667.jpg` - компактная полоса семян, выбранная грядка видна.
- `drag-move.jpg` - перенос яблони: исходное место прозрачное, сетка и клетка цели.
- `building.jpg` - строительство продолжается с ценой следующей грядки.
- `level-up.jpg` - новый уровень с открытыми наградами.
- `plot-card.jpg` - карточка политой посадки с таймером.
- `older-api-hint.jpg` - старый Farm API: полив отключён с объяснением.
