# PICK FARM v3 - снимки

Web export в Chromium, изолированный HTTP-fixture с настоящим движком, задержка сети
400 мс. Это не нативная приёмка.

- `daily-gift.jpg` - подарок дня при входе: 7 ступеней, текущий день выделен.
- `overview-locked-land.jpg` - открытый центр 12x12, закрытая земля темнее, таблички,
  коровник с коровами, деревья, кусты и пруд вокруг поля.
- `land-panel-667.jpg` - касание закрытой земли открывает расширение сбоку.
- `land-expanded.jpg` - после покупки участок 16x16.
- `coop-and-barn.jpg` - построенный курятник с тремя курами рядом с коровником.
- `milk-to-storage.jpg` - сбор молока: бутылки летят в склад, коровы снова голодные.
- `order-board.jpg` - доска: три покупателя с товарами, наградой и кнопками.
- `board-timers-667.jpg` - после выполнения и замены заказа - таймеры новых покупателей.
- `storage-goods.jpg` - яйца и молоко на складе рядом с урожаем.
- `legacy-protocol-2.jpg` - тот же клиент со старым API: без подарка, загонов и закрытой
  земли, поле 32x32 открыто.
