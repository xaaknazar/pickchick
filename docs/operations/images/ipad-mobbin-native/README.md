# Нативные скриншоты iPad

Снимки получены XCTest с физического iPad Air 13-inch M3, iPadOS 18.7.8,
PickChick Kiosk 0.1.0 (5). Это реальные экраны приложения, а не браузерные
фикстуры. Привязка сохранена, меню загружено с действующего API.

Проверка открывала меню и товар, без изменения корзины, создания заказа или
оплаты. verification.json связывает source, подпись, установку, CI, результаты
нативного теста и SHA-256 снимков. Сырые device identifiers, профили, credentials
и private логи остаются вне Git.
