# Локальный пилот кассы, кухни и табло

16 сентября владелец уточнил ближайший результат: два моноблока должны провести
заказ от кассира до приготовления/сборки/выдачи без терминала оплаты и ККМ.
LED-экран пока не подключён. Настройку через AnyDesk нужно заменить удобным
командным доступом; установка Codex непосредственно на Windows рассматривается
как дополнительный вариант, а не обязательная часть работы ресторана.

## Порядок запуска

1. Один раз настроить административный доступ Mac -> Windows на кассе, затем
   на кухне. Предпочтён OpenSSH Server, отдельный ключ администратора, проверенный
   отпечаток каждого Windows-хоста и доступ firewall только с адреса Mac.
   Прямой доступ требует общей LAN; для администрирования из другой сети
   предварительно нужен отдельный защищённый VPN-маршрут. Не открывать SSH
   в интернет. Этот доступ отделён от исходящего туннеля
   Windows -> VPS, который передаёт заказы. Имеющийся `inspect-native-ssh.ps1`
   проверяет только SSH Client и не подтверждает наличие административного SSH.
2. Закончить кассовый моноблок: обновить сохранённую установку, меню/модификаторы,
   личный вход, смены и режим `unpaid_service`. Заказ получает постоянный номер
   и сохраняется на локальном PostgreSQL, сразу создавая задания кухни.
   Кнопка кассира отправляет заказ без запроса оплаты. По ADR-0010 тестовое
   проведение не создаёт `paid`, выручку, чек или бонусы; будущие интеграции
   банка/ККМ сохраняются.
3. Подключить кухонный моноблок к кассовому edge через существующий LAN HTTPS
   gateway. Проверить один и тот же номер/состав, приготовление, сборку, готовность
   и выдачу. Личные роли и назначения станций сохраняются.
4. Проверить табло в отдельном клиентском окне. После выбора подключения LED
   вывести его как отдельный экран с колонками «Готовится» и «Готово», без имён
   и состава заказа. Для HDMI сначала подтвердить видеовыход моноблока; для
   Smart TV отдельно проверить браузер и защищённый локальный клиент.
   Текущий переключатель «Табло» внутри кухни сам по себе не подтверждает
   одновременную работу кухни и внешнего экрана.
5. Подключить долговечную синхронизацию с центральной базой и бэк-офисом.
   При доступном интернете worker доставляет изменения; после разрыва WAN
   досылает накопленное с подтверждениями и без повторного создания заказов.
   Cloud наблюдает локальные заказы, не подменяя их владельца.
6. Приёмка: заказ со сложными модификаторами, приготовление и выдача, отображение
   в бэк-офисе, потеря WAN и восстановление связи, перезапуск приложений/служб.
   Отдельно подтвердить автозапуск после перезагрузки Windows.

## Локальная сеть

Wi-Fi и Ethernet подходят при доступности устройств друг другу в сети ресторана.
Отключение интернета не должно отключать локальный маршрут касса -> кухня/табло.
Разрыв самой LAN/Wi-Fi прерывает передачу на кухню; касса должна явно показывать
состояние связи. Кассовый моноблок с сервером должен оставаться включённым.
Адреса закрепляются после проверки реальной маски/маршрутизации и изоляции Wi-Fi.
Работа ресторана не зависит от Mac, AnyDesk или запущенного Codex.

## Администрирование и границы готовности

На кассе ранее проверена Windows 10 Pro 1909 и PowerShell 5.1. Это удовлетворяет
минимуму OpenSSH 1809+, но наличие Server и возможность загрузить компонент
через Windows Update ещё нужно проверить на оборудовании.
[Установка OpenSSH Microsoft](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_install_firstuse).

Codex поддерживает запуск непосредственно в Windows. Для актуальной полностью
обновлённой Windows 10 документация обозначает best effort; совместимость
конкретной установки 1909 пока не проверена. Для переноса потребуется вход
в учётную запись владельца, отдельная рабочая копия репозитория и передача
состояния установки; наличие приложения не переносит автоматически локальные
файлы Mac или текущую задачу.
[Официальная документация OpenAI](https://learn.chatgpt.com/docs/windows/windows-app),
[матрица Windows](https://learn.chatgpt.com/docs/windows/windows-sandbox).

Это порядок физического запуска, не отчёт об установке. Собраны POS 0.3 и
Kitchen 0.2; на кассе последней подтверждена POS 0.1 и edge001-009. Новый
административный SSH, обновление моноблоков, LED и сквозной пилот не приняты.
