# Фотографии напитков iPad - 8 октября 2026

В коде киоска заменены изображения подходящих напитков на фотографии владельца.
Обрезка и удаление фона отдельно подтверждены владельцем. Piko яблоко и апельсин
подготовлены как два выбора вкуса существующего товара 200 мл. Это проверенный
этап исходников; серверный каталог не опубликован, установленная версия iPad
0.1.0 (6) этим этапом не обновлялась.

## Подготовка двух вкусов Piko

`packages/catalog-admin/src/piko-flavors.ts` преобразует актуальный payload:
сохраняет существующий Piko SKU, количество товаров (24 в fixture), объём,
канальные цены, остальные атрибуты; добавляет обязательный выбор одного из двух
вкусов без доплаты. Общая опция Piko в комбо разделяется с сохранением доплаты,
доступности, linked_product_id и общего количества вариантов по умолчанию.
Повторное применение идемпотентно; неоднозначные старые группы отвергаются.

Серверный payload не подменяется локально в контроллере. Исторический исходный
каталог и его утверждённый hash не изменены. Для реального выбора вкусов требуется
обычная публикация новой версии каталога и подтверждённая доставка на edge.

Офлайн-подготовка (после сборки catalog-admin):

```sh
node scripts/prepare-piko-flavors.mjs current-payload.json prepared-payload.json REVIEWED_INPUT_SHA256
```

Команда проверяет SHA256 прочитанного файла, создаёт новый файл с правами 0600,
не перезаписывает существующий и явно возвращает `published:false`.
Проверена на fixture: input SHA256
`4806cbeb49749555b59ad96e35e4b7708b2b6c5115b1b6c76684ceca124ec1ae`,
24 товара, published=false. Это не экспорт текущей production-БД.

## Проверки и доказательства

- catalog-admin build и 3 unit-теста: исходные данные неизменны, SKU/цены сохранены,
  комбо сохраняет доплату/выбор, повтор идемпотентен, неоднозначные данные отвергаются.
- kiosk TypeScript, ESLint, Prettier и UI architecture 4/4.
- Storybook production build; iOS Hermes и web export с локальными PNG.
- Browser: 768x1024, 820x1180, 1024x1366. Девять изображений в комбо и 11 историй
  изображений загружены; нет горизонтального переполнения и ошибок страницы.
  Выбор яблоко -> апельсин меняет настоящий источник картинки, текст и идентичность
  строки корзины, сохраняет 590 ₸ fixture. Сетевые обращения только localhost.
- Сопоставлены исходные снимки с обрезками: бутылки/крышки/упаковки целы, UI удалён,
  этикетки фотографические. Результат детектора Impeccable: пустой список.
- [Browser report](images/kiosk-drink-photos/browser/result.json),
  [комбо 768](images/kiosk-drink-photos/browser/combo-768.png),
  [Piko 768](images/kiosk-drink-photos/browser/piko-768.png),

Проверка выполнена на реальных компонентах в браузере с подготовленным fixture.
Установка и визуальная приёмка на физическом iPad, публикация каталога и подтверждение
edge этим этапом не выполнены. Реальные заказы и платежи не создавались.
