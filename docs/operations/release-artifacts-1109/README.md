## Новый архив оператора025

В утреннем протоколе оператор и помощники передавались отдельно от runtime.
Добавлен `scripts/build-queue-recovery-operator.py`: собирает15 файлов, в том числе
оператор,10 необходимых помощников/ledger,3 инструкции и manifest.
Он проверяет6 закреплённых зависимостей оператора и5 pins установщика backup
(ledger встречается в обеих группах), а также относительные JS/JSON-зависимости.
Git-объекты сохраняют проверенные LF-байты независимо от окончаний строк checkout.
Сборщик не исполняет PowerShell и не обращается к БД.

```sh
python3 scripts/build-queue-recovery-operator.py \
  --source /absolute/path/to/clean-reviewed-checkout \
  --expected-sha dbbf4aa8846f6510f6d4d556185c489426487c23 \
  --output /absolute/path/outside-checkout/operator025-dbbf4aa8.zip
```

Для исходникаdbbf4aa8 уже собран архив89851 байт, SHA256:
`9eb00cb8b826ba12e725c99e2d3dea6197fa58e17d9787dd3702bce356b13de4`.
[Квитанция сборки](operator025-dbbf4aa8.json).
Проверены7 unit-сценариев: комплектность/детерминизм, исключение приватных файлов,
грязный/неверный исходник, изменённый закреплённый помощник, symlink,
новая незапакованная зависимость, запрет перезаписи, отдельный CRLF clone.
В распакованном архиве все5 PowerShell-скриптов прошли parser на PowerShell7.6.9;
это не исполнение установщика и не новая Windows-приёмка.

Workflow `Queue recovery operator delivery` проверяет сборщик и публикует архив
с полным исходным SHA. В каждом запуске он относится к своему SHA; результат
для новой ветки нельзя называть архивомdbbf4aa8. Для выбранного релиза сверить
`sourceCommit`, содержимое manifest и SHA256 всего ZIP с квитанцией сборки.

Архив оператора **не содержит runtime, Node/PostgreSQL, ключи, owner.env, копию БД,
CloudReleaseReceipt или CI-proof** и всегда сообщает `deploymentReady:false`.
Это комплект этапа025, не финальный выпуск продаж026/кухни027/кассы028.
Применение остаётся по инструкции внутри архива с прежними guards, свежими
доказательствами и согласованным окном. Шаг020→023 не пересобирается этим инструментом.
