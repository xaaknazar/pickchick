## Что ещё не закрыто

**С4.** Cloud DB-шаг не развёртывает API и возвращает `releaseReady:false`.
Его проверка флагов опирается на текущие ACL-маркеры, а не на чтение среды API.
Cloud-proof Windows-оператора является проверяемой операторской квитанцией,
не прямой проверкой VPS. Остаются выпуск API072, проверки совместимости со
схемами 023/024 и сохранения флагов, восстановление настоящей резервной копии,
приёмка полного оператора на Windows, отдельный диск/ключ и окно установки.
Последующие 073/074 и 026-028 этим шагом не устанавливаются.

**К14.** Порт 43110 подготовлен для POS; 43100 остаётся за fulfillment.
Нет свежего read-only отчёта по реальной очереди и решения о пяти исторических
продажах. Первый запуск работника может отправить накопленные события.
Нужны решение, установка и проверка подтверждения в облаке. [PR319](https://github.com/xaaknazar/pickchick/pull/319) сохраняет
отдельное назначение для интеграционной ветки cutover.

**К15.** Проверены синтетические данные на PostgreSQL 18.6. Это не репетиция
на защищённой копии настоящей кассы и не проверка физического Windows/принтера.
На окончательном RC требуется повторить проверки; 18.3 остаётся только
историческим результатом первого прогона.

**Меню.** В стартовой фикстуре 49 отметок UNCONFIRMED, 38 позиций без KK,
30 без собственного фото. У всех 54 позиций отсутствуют цены Яндекс Еды и Glovo;
автоматическая подстановка цены зала не применялась. Нужны исправленные и
утверждённые управляющим листы, реальные снимки каталога/кассы, parity и только
затем публикация. Отсутствие ошибок схемы не подтверждает цены и состав.
