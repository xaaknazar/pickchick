# Раздел «Расходы» бэк-офиса

Запрос владельца от 11.11.2026: ввод расходов по точкам за день и за месяц, журнал, ОПУ,
сверка кассы, аналитика и закрытие месяцев, по логике платформы KEX GROUP. Раздел
переделывает прежние «Финансы» (cloud042 `bo_finance_*`): старые таблицы не меняются и
остаются для просмотра, новый учёт живёт в cloud077.

## Включение

- Миграция `db/cloud/migrations/077_cloud_backoffice_expenses.sql`, только новые таблицы.
- Флаг API `BACKOFFICE_EXPENSES_ENABLED` (по умолчанию `false`), нужен `BACKOFFICE_ENABLED`.
- Права роли API: `infra/staging/backoffice-expenses-grants.mjs` (сброс прав только на
  таблицы 077; при выключенном флаге только отзывает).
- Установка: охраняемые шаги `cutover-cloud-owner.mjs inspect-077`, `deploy-077`,
  `expenses-grants on|off`, `compose-expenses` и `compose-flag expenses`. 077 идёт после
  072-076. Владелец 11.11 решил ставить сразу, не дожидаясь 19.11: порядок в
  [cloud-expenses-now-1111.md](cloud-expenses-now-1111.md), копия базы перед миграцией.

## Данные

| Таблица              | Что хранит                                                                                                                                                                                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `bo_expense_entries` | записи: дата, точка (`NULL` = «Общие расходы компании»), статья, источник (`cash`, `kaspi`, `halyk`, `bank`), сумма в тиынах со знаком, месяц ОПУ, флаг «за месяц», контрагент, комментарий, автор, время, ревизия. Ячейка таблицы ввода (`cell`) одна на дату + точку + статью + источник |
| `bo_expense_rows`    | месяц ОПУ и комментарий строки таблицы ввода (новые ячейки строки берут их)                                                                                                                                                                                                                |
| `bo_expense_cash`    | касса точки за день: сальдо на начало (пусто = по отчёту кассира за прошлый день) и остаток по отчёту кассира                                                                                                                                                                              |
| `bo_expense_months`  | закрытые месяцы (кто и когда)                                                                                                                                                                                                                                                              |
| `bo_expense_log`     | журнал действий: добавил, изменил, удалил, строка, касса, закрыл и открыл месяц, доступ                                                                                                                                                                                                    |
| `bo_expense_access`  | доступ к разделу: руководитель, финансист, экономист, просмотр                                                                                                                                                                                                                             |

Закрытый месяц защищён дважды: сервер отвечает `MONTH_CLOSED`, а триггер 077 отклоняет
любое изменение записей, строк и кассы этого месяца (по дате и по месяцу ОПУ).

## Доступ

- Руководитель: владелец (роль «управляющий» во всех точках организации) или выданная
  роль `director`. Закрывает и открывает месяцы, выдаёт доступ.
- Финансист и экономист: вводят и меняют записи и кассу.
- Просмотр: только читает.
- Без выданного доступа раздел недоступен, проверка на сервере.

## Справочник статей

Один список на сервере: `packages/backoffice-core/src/expenses-catalog.ts`, отдаётся
экрану через `GET .../expenses/meta`. Код статьи не меняется, название можно менять.

## Выручка и себестоимость

- Выручка по дням и типам оплат: продажи кассы (cloud073, по рабочему дню продажи, возвраты
  и сторно по дню возврата, как в отчёте о продажах) и заказы приложения и киоска. Наличные →
  «Наличные», Kaspi терминал и Kaspi вручную, приложение и киоск → «Kaspi / Halyk / QR»,
  Яндекс, Glovo, Chocofood → «Прочие». Питание персонала и маркетинг не выручка. Wolt и
  Halyk на кассе пока нет.
- До 19.11 выручка в iiko и в базе её нет: только статья «Выручка вручную».
- Себестоимость по ТТК: стоимость документов автосписания (cloud075) по дню документа,
  минус их сторно. Пока автосписание не включено, данных нет и экран это пишет.
- Фудкост по блюдам: выручка строк чеков кассы и себестоимость их заказов, себестоимость
  заказа делится между строками по сумме.

## Расчёты

- ОПУ берёт записи по месяцу ОПУ, а не по дате. Движение денег в ОПУ не входит.
- Валовая прибыль = выручка + прочие поступления − себестоимость. EBITDA = валовая прибыль −
  расходы. Рентабельность = EBITDA / выручка.
- Разнесение общих расходов: общие расходы месяца делятся между точками пропорционально
  выручке точки за этот месяц, до тиына (метод наибольшего остатка). Месяц без выручки
  остаётся в колонке «Общие».
- Касса: должно быть = сальдо на начало + наличная выручка + прочие поступления наличными +
  снятие со счёта − расходы наличными − инкассация. Разница = по отчёту кассира − должно быть.
  Ненулевая разница даёт статус «!».
- Время и дни по Алматы (UTC+5).

## API

Префикс `v1/admin/backoffice/expenses`, токен бэк-офиса в `Authorization: Bearer`. Чтение
`GET`, запись `POST` (шлюз и прокси кабинета пропускают только эти два метода). Закрытый
месяц: `409 CONFLICT` с причиной `error.code = MONTH_CLOSED`.

| Запрос                                                        | Что делает                                                        |
| ------------------------------------------------------------- | ----------------------------------------------------------------- |
| `GET meta`                                                    | справочник, источники, типы выручки, точки, роль, закрытые месяцы |
| `GET entry?period=day&date=` или `?period=month&month=`       | всё для экрана «Ввод»                                             |
| `POST cell`                                                   | создать, изменить или удалить (пусто) ячейку                      |
| `POST row`                                                    | месяц ОПУ и комментарий строки                                    |
| `POST entries`, `POST entries/:id`, `POST entries/:id/delete` | запись с контрагентом, правка, удаление                           |
| `POST cash`                                                   | сальдо на начало и остаток по отчёту кассира                      |
| `GET journal`                                                 | журнал с фильтрами                                                |
| `GET pnl`                                                     | ОПУ по точкам или по месяцам                                      |
| `GET analytics`                                               | динамика, структура, сравнение точек, движение денег              |
| `POST months/:month/close`, `POST months/:month/open`         | закрыть и открыть месяц                                           |
| `GET access`, `POST access`                                   | доступ к разделу                                                  |
| `GET log`                                                     | журнал действий                                                   |
