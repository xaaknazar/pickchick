# Название точки в быстрой оплате

Владелец 06.11 утвердил макет: иконка, «С собой · Abay Plaza» или
«В зале · Abay Plaza» над суммой. Задача mobile-cart-location-1106,
база shared 1a9472f1.

## Изменение

Название берётся из справочника выбранного branch.id, как в шапке,
либо из имени этой же точки в модели. Неизвестный филиал не подменяется
первой точкой справочника. Убирается только начальное «ТЦ » или «ТРЦ »;
полное локализованное имя доступно VoiceOver. Без имени нет разделителя.

Способ получения, иконки, казахский системный шрифт и testID сохранены.
Длинное название сокращается многоточием. Плашка использует отступы16 pt
и ширину до390 pt, ручка64 pt; на экранах меньше360 pt одна миниатюра.
На обычной ширине история трёх фото сохранена. Оплата, восстановление
заказа, цены и API не менялись.

## Проверки

- Node mobile:586/586; Python mobile:96/96.
- Mobile typecheck и адресный ESLint PASS.
- Демо-плашка browser_cart_shortcut PASS: 320/393/768 pt и альбомный экран852x393,
  три вкладки, смена режима, сохранение порядка фото, открытие корзины по названию.
- Локальная сборка roadmap и 7/7 проверок PASS; онлайн-публикации нет.
- Браузерные ABIRL и AH PASS: 393x852/320x568, RU/KK/EN, короткий жест без отправки, полный жест с одним тестовым счётом, закрытый ресторан без оплаты. CI проверяется отдельно.
- Только локальные фикстуры. Реальных QR, счетов и платежей нет.

Первый запуск в новой рабочей копии обнаружил несобранные внутренние
пакеты; после их штатной сборки проверки повторены. Один Python-тест
требует локального сервера; повтор с доступом к localhost прошёл.
