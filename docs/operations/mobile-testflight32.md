# PickChick 0.2.0 (32): подготовка

По поручению владельца30.10 исправляется обнаружимость удаления аккаунта
для App Review и иконка вкладки Игры. Подробности и сценарий видео:
[App Review](mobile-app-review-1030.md).

Версия0.2.0 и Bundle ID kz.pickchick.app сохранены; следующий после31 номер32.
Профиль storefront: server auth, Kaspi и опубликованный каталог включены;
симулятор, неоплаченные тестовые заказы, Pick Farm выключены.

TypeScript и адресный ESLint PASS; 562 Node + 59 Python PASS.
Storefront browser_store_walk PASS:97 состояний, RU/KK/EN,320/393px,
вход в удаление через профиль, отказ без DELETE и успех с одним DELETE.
Это локальные фикстуры, не удаление действующего аккаунта. Полная CI,
archive/export/upload и доступность группы пока не подтверждены. Видео с физического iPhone запишет владелец после выпуска.
Реальные аккаунты не удалялись, платежи и счета не создавались.
Сервер, касса, iPad, публичный App Store и онлайн-пульт не обновлялись.
