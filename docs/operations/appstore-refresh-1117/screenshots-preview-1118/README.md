## Оформление и ограничения

Актуальный фон - синий шелковистый перелив с бирюзовыми и фиолетовыми отражениями. По просьбе владельца коробка и стопка игровых коробок заменены фингерсами и бургером из каталога приложения. Остальные мотивы - Алекс в очках, пламя, стакан и сердце. На каждом кадре три разных мотива, расположенных за экраном. Принцип размещения изучен по Drinkit, персонажи и мотивы созданы для Pick Chick. Еда взята из существующих catalog-cutouts без изменений: фингерсы - ранее созданная иллюстрация каталога, бургер - материал макета владельца. Это не новая фотосъёмка. [Происхождение и хеши](art/provenance.json), [промпты](art/prompts.md).

Рамка нейтральная серебристая, без заявления о соответствии конкретному устройству. Внутри - только неизменённые исходные изображения интерфейса и еды. Казахские фразы целиком набраны Arial Bold: комплектные Jost и Manrope не содержат всех необходимых казахских глифов.

[Новая переливающаяся обложка](../assets/header-iridescent-3840x1646.jpg) имеет размер 3840 x 1646. Для отдельного просмотра в локальной галерее добавить `?cover=1`. В App Store она не загружена.

Исходники в `sources/` сохранены без изменений. Это архивные web-снимки и демонстрационные экраны, не нативные скриншоты build40. Цены не проверены. Пути происхождения и SHA-256 записаны в manifest.

- Экран 2 временно показывает меню на одного, а не комбо для компании. Для финала нужен раздел больших комбо из build40.
- Экран 4 показывает режим «В зале» (DineIn), а не «С собой». Для финала нужна корзина build40 с выбранным режимом «С собой».
- Экран 5 использует старую короткую форму заказа. Для финала нужен согласованный пример нового статуса готовности из build40.
