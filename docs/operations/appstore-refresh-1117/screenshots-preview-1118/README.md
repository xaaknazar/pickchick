## Оформление и ограничения

Фон - фирменный синий градиент `#1B66D9` -> `#074DBB` (52%) -> `#073585`. Рамка нейтральная серебристая, без заявления о соответствии конкретному устройству. Использованы только исходные изображения интерфейса и еды, без перерисовки. Казахские фразы целиком набраны Arial Bold: комплектные Jost и Manrope не содержат всех необходимых казахских глифов; наличие этих глифов в системном Arial Bold проверено.

Исходники в `sources/` сохранены без изменений. Это архивные web-снимки и демонстрационные экраны, не нативные скриншоты build40. Цены не проверены. Пути происхождения и SHA-256 записаны в manifest.

- Экран 2 временно показывает меню на одного, а не комбо для компании. Для финала нужен раздел больших комбо из build40.
- Экран 4 показывает режим «В зале» (DineIn), а не «С собой». Для финала нужна корзина build40 с выбранным режимом «С собой».
- Экран 5 использует старую короткую форму заказа. Для финала нужен согласованный пример нового статуса готовности из build40.
