## Оформление и ограничения

Актуальный фон - синий шелковистый перелив с бирюзовыми и фиолетовыми отражениями. По просьбе владельца коробка и стопка игровых коробок заменены фингерсами и бургером из каталога приложения. Остальные мотивы - Алекс в очках, пламя, стакан и сердце. Владелец отклонил ряд над телефоном: теперь на каждом кадре три разных мотива расположены свободно по углам и бокам, с разной высотой, размером и поворотом. Слой стикеров выше телефона, все фигуры целиком в кадре. Их прозрачные прямоугольные границы местами касаются рамки; видимые изображения не скрывают текст и действия интерфейса. Принцип размещения изучен по Drinkit, персонажи и мотивы созданы для Pick Chick. Еда взята из существующих catalog-cutouts без изменений: фингерсы - ранее созданная иллюстрация каталога, бургер - материал макета владельца. Это не новая фотосъёмка. [Происхождение и хеши](art/provenance.json), [промпты](art/prompts.md).

Рамка нейтральная серебристая, без заявления о соответствии конкретному устройству. Телефон занимает 68% ширины и начинается на 28,5% высоты; отступ слева чередуется между 8% и 24%, освобождая место для стикеров. Внутри - только неизменённые исходные изображения интерфейса и еды. Казахские фразы целиком набраны Arial Bold: комплектные Jost и Manrope не содержат всех необходимых казахских глифов.

[Новая переливающаяся обложка](../assets/header-iridescent-hd-3840x1646.jpg) имеет размер 3840 x 1646. Для отдельного просмотра в локальной галерее добавить `?cover=1`. В App Store она не загружена.

После запроса HD четыре декоративные фигуры пересозданы отдельно в 1254 x 1254 вместо ячеек 512 x 512 общего листа. Для вертикальных макетов создан отдельный фон 941 x 1672; прежде увеличивался узкий фрагмент панорамы высотой 821 px. Широкий фон обложки заново отрисован в 1915 x 821. Генератор не выдал запрошенные 2160 x 3840 / 2048 x 2048: фактические размеры записаны, исходники не заявляются как нативный 4K. Макеты 1320 x 2868 и обложка 3840 x 1646 используют масштабирование фона. Фингерсы 1254 x 1254 и бургер 560 x 560 сохранены; они выводятся меньше исходного размера. [Точные запросы встроенного генератора](art/hd-generation-1118.json).

Исходники в `sources/` сохранены без изменений. Это архивные web-снимки и демонстрационные экраны, не нативные скриншоты build40. Цены не проверены. Пути происхождения и SHA-256 записаны в manifest.

- Экран 2 временно показывает меню на одного, а не комбо для компании. Для финала нужен раздел больших комбо из build40.
- Экран 4 показывает режим «В зале» (DineIn), а не «С собой». Для финала нужна корзина build40 с выбранным режимом «С собой».
- Экран 5 использует старую короткую форму заказа. Для финала нужен согласованный пример нового статуса готовности из build40.

## Проверка экспортов и финальная приёмка

После свободной расстановки проверены все 18 стикеров с учётом поворота: границы внутри полотна, пересечений с заголовками нет, слой выше телефона. Прямоугольные границы стикеров включают прозрачные поля; их касание рамки отражено в измерениях и дополнительно проверено визуально. Обе полосы просмотрены. [Измерения браузера](sticker-layout-check.json).

Размеры всех шести отдельных JPG проверены: 1320 x 2868 px. Замечания независимого ревью исправлены: экспорт полных страниц устранил обрезку, пояснения о временных экранах добавлены в сами макеты и обзорные полосы. Ведущий агент визуально проверил обе итоговые полосы, точное совпадение шести подписей и SHA-256 неизменённых исходников. Комплект готов для согласования оформления; для публикации ещё нужна свежая съёмка.

Перед финальной приёмкой и загрузкой в App Store необходимо заменить все шесть архивных экранов нативными снимками build40, проверить цены и повторно проверить готовые экспорты. Эти макеты предназначены только для предварительного просмотра владельцем.
