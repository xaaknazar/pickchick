# Четыре выбранных скриншота Pick Chick

18.11.2026 по следующему уточнению владельца удалены все внешние стикеры. Телефоны увеличены с 68% до 80% ширины кадра и подняты с 28,5% до 18% высоты, сохраняя общую центральную ось. Подписи, переливающийся фон и внутренние экраны сохранены.

| Порядок | Экран         | Подпись                  |
| ------- | ------------- | ------------------------ |
| 1       | Главное меню  | Сүйікті дәмің осында     |
| 2       | Микс Дуо      | Достармен бірге дәмдірек |
| 3       | Игры          | Ойна. Рекорд жаңарт.     |
| 4       | Статус заказа | Тапсырысың көз алдыңда   |

Текущий набор содержит только эти четыре кадра. Настройка комбо и корзина больше не входят в него. Прежний набор из шести хранится как история; не смешивать его с текущими файлами.

Первые три исходника сохранены побайтно в `sources/`, размер 1320 x 2868. Номер сборки отдельно не подтверждался. Цены не редактировались и независимо не проверялись. Четвёртый кадр снят с локальной галереи приложения, 440 x 956, без перерисовки интерфейса. OrderStatusScreen и OrderChef не отличаются между исходником 32 (e4eb91b5) и 40 (502743ce); оболочка OrderSheet менялась. Поэтому это пример дизайна, а не нативный снимок сборки 40. Пометка примера внутри приложения сохранена, реальные заказ и оплата не создавались. SHA-256 и точный способ получения записаны в [manifest.json](manifest.json).

Прежняя декоративная коробка больше не показывается; исходник оставлен для истории. Она создана встроенным генератором по оригинальным lid.png и front.png из макета владельца. PNG 1254 x 1254 с прозрачностью; это декоративная визуализация упаковки. [Промпт](art/generation-prompt.txt) и [происхождение](art/provenance.json).

Экспорты для просмотра имеют размер 1320 x 2868. Галерея: [четыре кадра](http://127.0.0.1:8877/selected-four-1118/), обзоры [1-2](preview-01-02.jpg) и [3-4](preview-03-04.jpg). Фон используется из соседнего каталога [art](../screenshots-preview-1118/art/); фактическое разрешение источников описано в его манифесте.

Владелец утвердил этот вариант и 18.11 поручил загрузить четыре кадра. Экспорты без внешних пометок МАКЕТ сохранены в черновике App Store Connect, в размерах 1320 x 2868 и 1206 x 2622. Четвёртый кадр сохранён с одобренным примером статуса и его внутренней пометкой; нативным снимком он не считается. Отправка на проверку не выполнялась. [Протокол загрузки](upload/README.md).
