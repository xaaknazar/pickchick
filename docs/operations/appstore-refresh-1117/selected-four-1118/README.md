# Четыре выбранных скриншота Pick Chick

18.11.2026 владелец сократил набор до четырёх кадров, затем попросил центрировать телефоны, заменить старый статус на дизайн приложения и убрать декоративный фингерс. Все телефоны теперь по одной центральной оси; фингерсы заменены фирменной коробкой FRIENDS BOX. Четвёртым показан встроенный пример актуального экрана готовности с Алексом. Подписи и переливающийся фон сохранены.

| Порядок | Экран         | Подпись                  |
| ------- | ------------- | ------------------------ |
| 1       | Главное меню  | Сүйікті дәмің осында     |
| 2       | Микс Дуо      | Достармен бірге дәмдірек |
| 3       | Игры          | Ойна. Рекорд жаңарт.     |
| 4       | Статус заказа | Тапсырысың көз алдыңда   |

Текущий набор содержит только эти четыре кадра. Настройка комбо и корзина больше не входят в него. Прежний набор из шести хранится как история; не смешивать его с текущими файлами.

Первые три исходника сохранены побайтно в `sources/`, размер 1320 x 2868. Номер сборки отдельно не подтверждался. Цены не редактировались и независимо не проверялись. Четвёртый кадр снят с локальной галереи приложения, 440 x 956, без перерисовки интерфейса. OrderStatusScreen и OrderChef не отличаются между исходником 32 (e4eb91b5) и 40 (502743ce); оболочка OrderSheet менялась. Поэтому это пример дизайна, а не нативный снимок сборки 40. Пометка примера внутри приложения сохранена, реальные заказ и оплата не создавались. SHA-256 и точный способ получения записаны в [manifest.json](manifest.json).

Коробка создана встроенным генератором по оригинальным lid.png и front.png из макета владельца. PNG 1254 x 1254 с прозрачностью; это декоративная визуализация упаковки. [Промпт](art/generation-prompt.txt) и [происхождение](art/provenance.json).

Экспорты для просмотра имеют размер 1320 x 2868. Галерея: [четыре кадра](http://127.0.0.1:8877/selected-four-1118/), обзоры [1-2](preview-01-02.jpg) и [3-4](preview-03-04.jpg). Фон и декоративные фигуры используются из соседнего каталога [art](../screenshots-preview-1118/art/); фактическое разрешение источников описано в его манифесте.

Это предпросмотр для владельца. Загрузка в App Store и отправка на проверку этим изменением не выполнялись. Перед загрузкой принять оформление и заменить пример статуса нативным снимком выбранной сборки.
