# Четыре выбранных скриншота Pick Chick

18.11.2026 владелец сократил набор до четырёх кадров. Три новых снимка переданы им в чате, четвёртым взят прежний статус заказа из макетов. Оформление, четыре подходящие утверждённые казахские подписи, переливающийся фон и свободно расположенные стикеры сохранены.

| Порядок | Экран         | Подпись                  |
| ------- | ------------- | ------------------------ |
| 1       | Главное меню  | Сүйікті дәмің осында     |
| 2       | Микс Дуо      | Достармен бірге дәмдірек |
| 3       | Игры          | Ойна. Рекорд жаңарт.     |
| 4       | Статус заказа | Тапсырысың көз алдыңда   |

Текущий набор содержит только эти четыре кадра. Настройка комбо и корзина больше не входят в него. Прежний набор из шести хранится как история; не смешивать его с текущими файлами.

Исходники сохранены побайтно в `sources/`; SHA-256 и происхождение записаны в [manifest.json](manifest.json). Первые три имеют исходное разрешение 1320 x 2868. Номер сборки на снимках не виден и отдельно не подтверждался. Цены не редактировались и независимо не проверялись. Прежний статус остаётся архивным примером и явно так подписан.

Экспорты для просмотра имеют размер 1320 x 2868. Галерея: [четыре кадра](http://127.0.0.1:8877/selected-four-1118/), обзоры [1-2](preview-01-02.jpg) и [3-4](preview-03-04.jpg). Фон и декоративные фигуры используются из соседнего каталога [art](../screenshots-preview-1118/art/); фактическое разрешение источников описано в его манифесте.

Это предпросмотр для владельца. Загрузка в App Store и отправка на проверку этим изменением не выполнялись. Перед загрузкой отдельно принять финальный набор и архивный источник статуса заказа.
