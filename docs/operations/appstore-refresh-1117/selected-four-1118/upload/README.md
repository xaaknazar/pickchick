# Четыре скриншота в App Store Connect

18.11.2026 владелец утвердил последний вариант и поручил загрузить четыре скриншота. Сохранены в черновике iOS 1.0.2 приложения Pick Chick (6809208492).

- Порядок: главное меню, Микс Дуо, игры, статус заказа.
- Основная локализация: русский. Английский (Великобритания) использует тот же набор основной локализации. Казахские подписи сохранены по выбору владельца.
- Большой iPhone: 1320 x 2868; средний обязательный размер: 1206 x 2622. По четыре файла в каждом.
- Прежние шесть кадров сняты со страницы в обеих группах; по подтверждению Apple они остаются в Библиотеке материалов.
- После перезагрузки страницы обе группы показывают 4 из 10 и правильный порядок. Остальные обычные размеры iPhone наследуют новый набор. Необязательный iPhone Duo остаётся без отдельного набора.
- Удалены только внешние служебные подписи МАКЕТ. Исходные экраны не перерисованы; четвёртый остаётся одобренным веб-примером статуса с видимой пометкой внутри приложения. Это не нативный снимок сборки 40.
- Версия на проверку не отправлялась. Билд, описание, обложка, публикация и другие платформы этой операцией не менялись.
