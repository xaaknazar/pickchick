## Исправления, выявленные при выпуске

Первый кандидат был остановлен до изменения gateway: встроенный fetch
закреплённого Node отклонял порт 4190 с `bad port`. Сам сервис возвращал 200
через HTTP; внутренний порт заменён на 4192.

Второй кандидат автоматически вернул прежний gateway: проверка хеша ограничивала
чтение файла восемью МиБ и неверно сравнивала видео. Проверка теперь читает
файлы полностью потоками по одному МиБ. Добавлен regression с большим видео.
Прежние файлы не были изменены. Первый неуспешный контейнер удаляется только
после проверки владения и остановки, без удаления постоянных данных.

Итоговые проверки: 7 Node/API, 13 deployment guards, браузерные сценарии на
1440/390/320 px, общий build/typecheck/lint/format, 78 корневых unit,
контракты и каталог дизайна. Ключ, резервные копии и приватные журналы выпуска
остаются вне Git и публичной раздачи.
