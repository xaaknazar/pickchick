## Код сотрудника

На Mac подготовлен отдельный скрытый ввод через штатный scripts/kiosk-staff-pin.mjs.
Код вводится дважды, не выводится, не передаётся в аргументах, не сохраняется и
не попадает в чат. Только верификатор сохраняется в закрытом файле 0600 вне Git.
В Compose символы доллара экранируются; до применения проверяется точное совпадение
разрешённого значения с результатом docker compose config, после - с окружением API.

## Установщики

- infra/staging/kiosk-connection-release.py: inspect сохраняет закрытый baseline
  и проверяет Caddy; apply выполняет одну вставку, reload и проверки соседей;
  rollback возвращает исходный файл при совпадении состояния. При неизвестном
  результате команды блокировка сохраняется для диагностики.
- infra/staging/kiosk-staff-release.py: отдельная подготовка и установка верификатора
  с проверкой образа, окружения, соседей и привязки. Baseline API получен без применения: текущий образ, окружение,
  схема/права БД, привязки и публичные ответы проверены; код сотрудника ещё не установлен.

Полноценная приёмка на iPad проводится отдельно: открыть киоск, проверить отсутствие
ошибки связи при ожидании дольше 30 секунд и вход в действия сотрудника новым кодом.
Проверка доступности без авторизации не заменяет эту приёмку.
