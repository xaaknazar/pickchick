### Остановка и проверенный откат

Первая установка после успешных миграций остановилась на именованной проверке
`runtime.config_mounts_labels`: Compose сменил служебную метку environment_file,
хотя реальные значения окружения не менялись. Старый API восстановлен; повторная
проверка потребовала восстановить и прежний путь env-файла в метаданных Compose.
Выполнено пересоздание только API с прежним образом и прежними путями.
Результат `ROLLBACK_VERIFIED`, старый API здоров, заказы и соседи совпадают.
База не восстанавливалась поверх рабочей, миграции 079/080/081 оставлены.

Оператор исправлен так, чтобы использовать исходные пути env из baseline.
В разрешённом сравнении resolved Compose учтено экранирование `$$`; реальные
переменные контейнера по-прежнему проверяются побайтно. Код сотрудника не менялся.
30 локальных проверок охран прошли. Продолжение выполнено отдельным runtime-only
оператором, который не запускает миграции, после новой копии и восстановления.
