# Mobizon: размещение ключа и проверка аккаунта

7 сентября 2026, 06:23 UTC. По поручению владельца подготовлен доступ к Mobizon
с VPS PickChick. Это настройка секретов и read-only проверка аккаунта;
серверный телефонный вход и доставка OTP не включены.

## Размещение

- Приватный серверный файл: `/opt/pickchick-staging/secrets/phone-verification.env`.
- Каталог сервера имеет права 0700, файл — 0600; владелец `pickchick-ops`.
- Локальная копия: `.local/phone-verification.env`, права 0600, исключена из Git.
- Ключ передан через SSH standard input, а не параметры процесса; значения
  секретов и полный ответ провайдера не выводились в команды или GitHub.
- `PHONE_DELIVERY_PROVIDER=disabled`; имя отправителя не выдумывалось.

## Проверка

С VPS выполнены HTTPS POST на фиксированный host `api.mobizon.kz`, без
перенаправлений; API-ключ передан в теле запроса. Использованы только методы
чтения:

| Метод                | Результат                                     |
| -------------------- | --------------------------------------------- |
| `user/getOwnBalance` | API code 0; доступ с VPS подтверждён          |
| `alphaname/list`     | API code 0; зарегистрированных отправителей 0 |

Баланс и ответы хранятся только в закрытом отчёте аккаунта. Реальных SMS
отправлено 0. Платные методы отправки/проверки получателя не вызывались;
имена отправителя и платные услуги не регистрировались.

Основания методов: [User API](https://mobizon.kz/help/api-docs/user),
[официальный пример alphaname/list](https://github.com/mobizon/mobizon-php/blob/master/docs/examples/alphanames.php),
[ссылка Mobizon на SDK](https://mobizon.kz/integration/api).

## Оставшаяся работа

Подтвердить имя отправителя в кабинете и операторский OTP-шаблон, тариф и лимиты
расходов; затем завершить серверный OTP/customer/consent/session domain и новую
мобильную сборку. Успех чтения баланса не подтверждает доставку SMS или владение
телефоном. Регистрация подписи/шаблона — внешняя зависимость.

Контейнеры, API release, БД, gateway и TestFlight на этом этапе не изменялись.
Существующий TEST-вход и бессрочные TEST-доступы сохранены.
