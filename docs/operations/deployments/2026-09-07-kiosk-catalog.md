Опубликованный образ построен из чистой отдельной рабочей копии точного SHA
после [успешного CI — четыре jobs](https://github.com/xaaknazar/pickchick/actions/runs/34106813343).
Схемы и миграции не менялись; provision не запускался. Перед обновлением проверены
хеши всех строк public-таблиц и значения sequence, новая зашифрованная копия
восстановлена отдельно и сравнена с живой БД.

Заменён только сервис API через `up --no-deps --wait api`. Readiness, capabilities,
оба представления каталога и версия образа проверены после запуска. Состояние
всех прежних заказов, задач, actors, ledger и других таблиц/sequence совпало.
Контейнеры БД/Redis, web release, общий ingress и соседние приложения сохранены.
API current symlink переведён на проверенный release. Подготовленный откат
использовал бы прежний совместимый API без восстановления данных поверх live;
применять его не потребовалось.

Сам rollout не создавал гостевых сессий/заказов и не обращался к SMS/банку/ККМ.
Связный заказ из нативного iPad проверяется отдельно после окончания rollout:
[протокол приложения и кухни](../../../tests/operations/verification-kiosk-native-2026-09-07.md).

В mobile 4/5 уже есть ресурсы чая и воды; их фото исправляются после обновления
каталога. Новый `shot.jpg` не включён в эти старые binary: для бургера используется
их штатный безопасный fallback до следующего мобильного выпуска. Новый киоск и
актуальный mobile source включают оригинальную фотографию; совместимость
контракта со старым приложением проверена.
