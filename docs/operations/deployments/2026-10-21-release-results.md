## Откат и оставшиеся зависимости

Старые образы и конфигурации сохранены. API откатывается своим оператором,
без восстановления рабочей БД; схема068 остаётся. Gateway возвращает только
свой прежний compose/pointer. Worker возвращает прежний образ с сохранённым
окружением. Кабинет имеет сохранённый предыдущий контейнер и копию настроек.
Не повторять уже выполненные immutable-попытки и не снимать чужие блокировки.
Для кассы после запуска нового процесса запрещён слепой возврат старых readers:
новые форматы данных требуют проверки совместимости и исправления вперёд.

Акция, push на сервере, ручные возвраты и автоматическое продление ключа остаются
выключены. Push069 не применялась. Каталог, цены и PIN сотрудников не менялись.
Ключ кассы действителен до20.11.2026 12:34:54 Алматы.

Отдельно остаются: код сотрудника киоска, адрес HTTPS фотопринтера и физический
доступ к iPad; Telegram-бот/чат мониторинга и сутки shadow-приёмки; независимое
хранилище резервных копий и решение о PITR; фискализация, юридические тексты,
контакт поддержки, production-домен и требования публичного App Store.
Read-only проверка VPS подтвердила: watchdog пока не установлен, у оператора
нет беспарольного sudo для установки systemd timer. Эти внешние зависимости
не маскируются готовностью кода. Техническая доставка не означает физическую
приёмку владельцем. Онлайн-пульт
этим checkpoint пока не опубликован.
