## Подготовленный шаг API

Оператор `infra/staging/release-runtime-1021.py` сохраняет установленную схему068,
права, окружение, флаги и соседние контейнеры. Между принятым shared и кандидатом
разрешены только сам оператор, его тест и этот протокол/журнал. Полная CI точного
опубликованного кандидата обязательна. Миграция push069 не применяется.

Исходные закреплённые значения:

- API `5b6f846b80785f915e9f8dd7d45fa72fd4bc13ee`.
- Image `sha256:e1b4a09a3c8f2cb32ed6f7b40f8ef1a864737506868ce95329a1feb2fa3173ca`.
- Public `76902fa4b8403f9084c0028fa16f02b8ec155586`.
- Compose SHA256 `e40ee261c23d8de8e7649f1d86db87ab0d095c75a84ad1230ef31c59d2f012fb`.
- Gateway SHA256 `f9e758ce74a4fe3b9fab6ca939920c8f5856fc2376d7c38565e92068884b2eee`.

Порядок: свежие refs/резервы; чистый опубликованный SHA; полная CI; `prepare --apply`;
`apply --apply`. Оба действия требуют всех пяти закреплённых значений, SHA/ветки,
пути SSH-ключа и CI proof. Применение дополнительно требует локальную age identity
с правами0600. Значения секретов оператор не печатает.

Перед переключением: зашифрованный дамп и таблица контрольных количеств; проверка
checksum; восстановление в отдельный контейнер без внешней сети; воспроизведение
прав runtime; запуск нового API и Redis в той же изолированной сети. Проверяются
readiness, сохранение gates capabilities, чтение каталога/доступности и отсутствие
изменений количества строк. Зашифрованная копия переносится также на этот Mac.

После переключения: точный image/SHA, health, схема/права, публичные GET, окружение,
флаги, gateway, банковские обработчики и остальные контейнеры. Любая ошибка
сохраняет принадлежащую операции блокировку для разбирательства.

Откат: тот же оператор `rollback --apply` с исходными pins и тем же candidate SHA.
При оставленной блокировке нужен её точный `--owner-id` и совпадающее локальное
свидетельство. Возвращается только прежний API image/pointer; рабочая база не
восстанавливается и история операций не удаляется. Схема068 остаётся. Чужую
блокировку не снимать; при неизвестном результате сначала проверить фактический
image/pointer. В случае отката финансовые действия ограничить до восстановления
совместимого API/интерфейса.
