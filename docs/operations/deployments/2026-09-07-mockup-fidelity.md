## Откат

Предыдущий web release — `d644822c3085348b66ea63d75bb753869d2d3829`.
При регрессии запустить его сохранённый Compose для одного gateway
(`up -d --no-deps --wait gateway`), проверить ingress/static, затем вернуть
public-https/current. API, база и общий Caddy при таком откате не затрагиваются.
Восстановление backup поверх рабочей базы для отката UI не требуется.

Это не production-внедрение SMS/Kaspi/ККМ/лояльности и не нагрузочная приёмка
миллиона профилей / 1 000 активных заказов. Эти Gate остаются в основном плане.
