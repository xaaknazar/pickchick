остальные байты и resolved config неизменны. 23/23 офлайн-теста PASS.

- API release `7e3120438461cbe561b01a587578060ff2cd9d3b`, прежний Compose;
- public release `21e95fe2dbbf8ff9abe167f8e40b6528b271fd3b`, прежний Compose
  и gateway.Caddyfile;
- канонический кабинет - остановленный контейнер
  `pickchick-staff-login-backup-a728cd318558` с прежним ID/image и копией
  private configuration в закрытом каталоге backoffice-login этого SHA.

При полном откате сначала вернуть штатным способом прежний staff-login,
проверив владение текущим контейнером и release lock. Затем оператор
`deploy-api-web.py rollback` с закреплёнными baseline SHA-256
`c57c75b6a64658a0827993ef2b17c08beb5730f51be912711718d17f6a7c0b3d`
и owner UUID `5872acfc-b34f-46f2-a2c3-fb3f5045602d` возвращает только свои
API/gateway и указатели, проверяя прежние образы, файлы, соседей и health.
При чужом состоянии или неизвестном исходе остановиться и сохранить lock.
Схему не понижать, рабочую базу поверх заказов не восстанавливать.
