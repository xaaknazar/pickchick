# Подготовка HTTPS pickchick.kz - 28 сентября 2026

## Подготовлено, ещё не применено

DNS авторитетного PS.kz уже возвращает apex/api → 185.129.51.103; www CNAME.
HTTPS будет дополнительным входом в текущий gateway. Старый nip.io сохраняется.
Служебные страницы перенаправляются на старый адрес, чтобы не менять их cookie,
Origin и доступы вместе с доменом. TipTopPay callbacks на новых именах пока
отвечают 503: приём денег и записи в коммерческую БД этим выпуском не открываются.

`infra/domains/release-alias.py` проверяет полный зелёный Foundation CI точного
SHA, исходные API/public pointers и SHA-256 обоих Caddyfile, готовность API и
здоровье контейнеров. При apply занимает штатный `.market-release.lock`, сохраняет
точные байты исходной конфигурации и CI proof в приватном каталоге domains на VPS.
Кандидат начинается с прежней конфигурации байт в байт; Caddy проверяется и
перезагружает конфигурацию через stdin без перезапуска контейнера. Файл сохраняет
inode и владельца; однократный изолированный writer монтирует только этот файл,
работает с его существующим UID/GID, без сети и дополнительных capabilities.

После применения проверяются доверенный TLS всех трёх имён, HSTS, одинаковые
capabilities старого/нового адресов, 503 платежного маршрута, редиректы служебных
страниц и www, неизменность idrink и дат запуска контейнеров. При определённом
сбое возвращается backup; при timeout/неподтверждённом откате lock сохраняется.

## Почему остановилась предыдущая CI

Логи GitHub теперь получены через штатный connector. В e4d469e ошибка форматирования
handoff.md остановила build/static; в базе 9cc6dd8 browser_cart_sheet ожидал видимый
текст «Сохранить» и прежние modifier selectors. Фотостраница показывает цену,
а действие описано accessibilityLabel; замена напитка теперь подтверждается
«Готово» с сохранением прямо в корзину. Проверка обновлена под этот путь.
Аналогично актуализирован complete_catalog: пищевая ценность в окне, выбор напитка
через picker и семь допов без уже включённого малого соуса. Проверки сумм,
состава, сохранения и идемпотентного восстановления не удаляются.

Локальный `pnpm check` прошёл полностью. Caddy 2.11.4 подтвердил candidate;
четыре теста deployment guards прошли. HTTP-проверка TipTopPay включена в CI.
Выпуск пока ожидает новую полную CI, онлайн-roadmap не обновлён.
