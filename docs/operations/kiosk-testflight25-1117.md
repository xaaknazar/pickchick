# Киоск 0.1.0 (25) - терминал Kaspi и несколько точек

Владелец разрешил внутренний TestFlight kz.pickchick.kiosk с ADR-0018/0019.
Основа приложения bf325a47fea53519906fe9bc86816698249796de, PR388 и PR394.
В Apple 17.11 проверены прежняя версия 0.1.0 и группа PickChick Kiosk Internal;
последняя загруженная сборка 15. На iPad ранее установлена 24 по кабелю.
Следующий номер 25. Версия, Bundle ID, Apple Team и SecureStore сохраняются.

Поддержка --kiosk-photo-disabled и её проверки перенесены без изменений из
проверенного 3f04e86c (PR387). Фотопринтер отложен владельцем; сетевой адрес
не подставляется, данные подключения и привязка киоска не удаляются.
Профиль kiosk-production, EXPO_PUBLIC_KIOSK_COMMERCIAL=1,
API https://api.pickchick.kz. Сохраняются NSAllowsLocalNetworking и описание
локальной сети из принятого исходника. Apple review demo не включается.

Локально 322 kiosk tests и 46 iOS release tests, TypeScript киоска и зависимостей,
ESLint и адресное форматирование PASS. Нативный archive/export/upload только
после полной Foundation CI точного коммита. Сейчас это кандидат, ещё не IPA
и не доступная в TestFlight сборка. Контрольную оплату проводит владелец.

После облачного выпуска проверить без денег config и охрану маршрутов,
после нативной загрузки - номер, Bundle ID, production API, коммерческий режим,
отключённую печать, подпись и назначение внутренней группе. На iPad владелец
разрешает локальную сеть, подключает свой терминал и проводит контрольную оплату
с подтверждением появления заказа на кухне. Физическая приёмка пока не выполнена.
