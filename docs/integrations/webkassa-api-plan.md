# Webkassa API: автоматические фискальные чеки кассы

Начато 16.11.2026 по просьбе владельца. План для владельца:
<https://claude.ai/artifact/W8uxeoVkeb5xKfwFfAkqGM>. Продолжает
[ADR-0015](../architecture/adr/0015-pos-sales-manual-fiscal.md) (`manual_webkassa`) и
[обследование кабинета 28.09](webkassa-live-access-2026-09-28.md).

## Состояние

- Сделано: клиент `packages/local-orders/src/webkassa-client.ts` (Authorize, Check, повтор с тем же
  `ExternalCheckNumber`, обновление токена, проверка денег до отправки) и тесты на имитаторе
  `packages/local-orders/tests/webkassa-client.test.mjs`. Реальная Webkassa не вызывалась.
- Поля и коды ошибок API **не сверены** с документацией поставщика: её и тестовый X-API-KEY
  владелец запрашивает у Webkassa. До сверки клиент не подключается к кассе.

## Ждём от владельца

1. Тестовый кабинет Webkassa, тестовую кассу, X-API-KEY, документацию и Postman; затем боевой ключ
   кассы №2 «Peak Group 4 мкр».
2. Отдельного кассира Webkassa для PickChick (логин и пароль только в приватный файл сервера точки).
3. SWK/РНМ, секции и налог кассы №2; решение бухгалтера по НДС, типам оплаты (Kaspi-терминал -
   карта, Kaspi вручную - мобильный платёж?) и чекам агрегаторов.
4. Единственный исполнитель чека: пока iiko пробивает по кассе №2, боевые чеки PickChick не
   включаются.
