# Киоск iPad — утверждённый редизайн (2026-10-13)

Владелец утвердил экраны от старта до умных допов. Всё, что после допов (экран Kaspi QR, ошибки оплаты, диалоги, номер заказа), **остаётся как есть** — не трогать.

Картинки утверждённых экранов лежат в `images/`. Размер макетов — 1024×1366 (iPad Pro 12.9″) в логических точках киоска; масштаб как сейчас: `v(n)=round(n*1.25*scale)`, `scale = clamp(width/1024, 0.8, 1.08)` (`apps/kiosk/src/theme.ts`). В спецификации ниже px даны в координатах макета 1024 — переводить через `v()`/`scale`.

## Новый путь заказа

Старт → «Как будете есть?» → Меню (бенто) → «Оформить заказ» → **Умные допы** → существующий экран оплаты Kaspi QR → существующий экран номера заказа.

- Отдельную страницу корзины «Ваш заказ» **убрать из пути**. Кнопка «К оплате» на допах ведёт сразу на текущий экран оплаты.
- Если корзина пуста, «Оформить заказ» в меню неактивна (экран пустой корзины больше не нужен).

## 1. Старт (`images/start.webp`)

Экран **без изменений** (видео, логотип, человечки, «Коснитесь экрана, чтобы начать», размеры и позиции). Меняются три вещи:

1. **Выбор языка** — та же геометрия, фон стекло: `rgba(2,10,31,0.55)`, рамка `1px rgba(255,255,255,.18)`, `backdrop-filter: blur(14px)`.
2. **Чип «Оплата через Kaspi QR»** (слева внизу, на месте старого): высота 75, радиус 38, `padding 0 26 0 12`, фон `rgba(2,10,31,.28)`, рамка `1px rgba(255,255,255,.2)`, blur 14; иконка Kaspi 50×50 круглая; текст Montserrat 700 24.
3. **Кнопка «СДЕЛАТЬ ЗАКАЗ» — анимация «Салют»**, цикл 2.8 с:
   - кнопка «пружинит»: `0% scale 1 → 3% .965 → 9% 1.045 → 16..100% 1` (ease-out);
   - по кнопке проходит блик: полоса 18% ширины, `linear-gradient(100deg, transparent, rgba(255,255,255,.65), transparent)`, `skewX(-20deg)`, `left -35% → 125%` на 6–50% цикла;
   - из краёв кнопки разлетаются 14 частиц (кружки 16px и четырёхлучевые звёзды 22px, цвета `#FFD166 / #FFFFFF / #FF6900`): появление на 4–8%, разлёт на 60–120px наружу к 70%, затем исчезают;
   - стрелки на кнопке **нет**;
   - при «уменьшить движение» — всё статично, частицы скрыты.

## 3. Меню — бенто (`images/menu-*.webp`)

### Шапка

Строка на `top 24`, высота 80: стеклянный круг-крестик 64 → логотип 78×72 → «Меню» (Montserrat 900 30) / «ТЦ Abay Plaza» (17, 75% белого) → стеклянный сегмент «В ЗАЛЕ / С СОБОЙ» (высота 64, кнопки 52, активная оранжевая) → стеклянный сегмент «KZ / RU / EN» (кнопки 70).

### Колонка разделов (слева)

`left 16, top 128, width 170`, до нижней панели; плитки высотой до 150 (сжимаются на меньших iPad, min 104), gap 12, радиус 28. Обычная — белая, текст `#15213A`; активная — `#FF6900`, белый текст, фото на белой подложке. Фото раздела 104×88 `contain`. Подписи: КОМБО, НА ДВОИХ, НА КОМПАНИЮ, ДОПЫ, НАПИТКИ.

### Сетка (справа)

Область `left 202, right 16, top 128, bottom 156`, gap 16, ряды — `fr`, поэтому сетка тянется по высоте экрана.

**Первая плитка — хит раздела, на всю ширину** (баннер `apps/kiosk/assets/v3/billboard-master.webp` на фоне, фото позиции справа 56% ширины `contain` + `mix-blend-mode: multiply`, слева ярлык, название Montserrat 900 46, цена 38 + кнопка «Выбрать»):

| Раздел      | Ярлык        | Хит          |
| ----------- | ------------ | ------------ |
| Комбо       | ХИТ НЕДЕЛИ   | Master Combo |
| На двоих    | ХИТ НА ДВОИХ | Фингер Дуо   |
| На компанию | ДЛЯ КОМПАНИИ | 25 фингерсов |
| Допы        | ЛЮБИМЫЙ ДОП  | Бургер       |
| Напитки     | ФИРМЕННЫЙ    | Лимонад      |

Хит раздела — настраиваемый (флаг в каталоге или первая позиция), выше — значения по макету.

**Остальные позиции — правило по количеству (N = все позиции раздела):**

- N = 3: 2 колонки; ряды `0.8fr 1.25fr`; под хитом 2 высокие карточки.
- N = 4: 2 колонки; ряды `1fr 1fr 1fr`; слева высокая карточка на 2 ряда, справа 2 маленькие.
- N ≥ 5: 3 колонки; ряды `0.85fr` + `1fr` × ⌈(N−1)/3⌉; если в последнем ряду пусто, последняя карточка растягивается на оставшиеся колонки и становится горизонтальной (фото слева 58%, текст справа).
- Больше рядов, чем помещается, — раздел прокручивается.

### Карточка позиции

Кремовая карточка. **Фото занимает всё место, кроме нижней полосы текста** (flex-колонка: блок фото `flex:1`, `object-fit: contain`, `mix-blend-mode: multiply`). Фото брать с обрезанными белыми полями (`apps/kiosk/assets/v3/photos/*` — при необходимости подрезать поля при сборке ассетов).

- Ярлыки: «ХИТ» (Pick Combo), «НОВИНКА» (Solo Combo), «ОСТРОЕ» (соус острый), «СВОЙ РЕЦЕПТ» (холодный чай) — по флагам каталога.

## 4. Умные допы (`images/upsell-*.webp`)

Открываются после «Оформить заказ». Шапка: стеклянная «‹ Меню», заголовок «Добавим к заказу?», подзаголовок по правилу; справа язык и «?». Под шапкой шаги-пилюли: Меню ✓ → Допы (активно) → Оплата → Номер заказа.

**Правило подбора (крупная плитка сверху, на всю ширину):**

- в заказе есть фингерсы (Pick/Master/Solo Combo, дуо с фингерсами, фингерсы) и нет бургера → «Добавьте бургер», ярлык «К ФИНГЕРСАМ», подзаголовок «Вы взяли …— к фингерсам подобрали»;
- в заказе есть бургер и нет фингерсов → «Добавьте фингерсы», ярлык «К БУРГЕРУ»;
- если есть и то и другое — показать хит, которого нет в заказе (например, лимонад крупно).

**Всегда, в любом заказе:**

- ряд «Соусы — к любому заказу»: Фирменный (ярлык ХИТ), Острый (ОСТРО), Сырный (НОВЫЙ);
- ряд «Напитки»: Лимонад 0.5 л — широкая карточка с ярлыком «НАШ ЛИМОНАД» (`#FFC21A`), Холодный чай, Coca-Cola.
- Уже добавленное: зелёная рамка `0 0 0 4px #2E9E5B` и зелёная кнопка с галочкой вместо «+». Позиции, которые уже в корзине, не предлагать.

Нижняя панель: «В заказе: …» + сумма; стеклянная «Без допов» и оранжевая «К оплате →» (обе ведут на существующий экран оплаты).

⚠️ **Сырного соуса нет в каталоге.** В макете фото сливочного соуса из `apps/mobile/assets/catalog-cutouts/signature-small.png` и цена 390 ₸ — заглушка. Нужна позиция в каталоге (фото и цена от владельца); пока её нет — плитку не показывать.
