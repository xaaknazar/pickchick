# Дизайн-система PickChick v0.2

## Визуальная основа

Мобильное приложение использует синюю тему из переданного App v2: фон #04143A,
карточки #0A2050, Jost для заголовков и Manrope для текста. Киоск — светлый каталог
с синей фирменной шапкой и оранжевыми действиями. Кухня — светлая с белыми тикетами.
Табло разделено на светлую и синюю колонки. Текущий бэк-офис использует светлую
рабочую поверхность #F5F7FB, белые формы и таблицы, тёмно-синюю навигацию
#04143A, Inter и компактные таблицы. Касса использует материалы киоска и кухни.
[Точное соответствие источникам](reference-alignment.md).

Общий источник — [tokens.json](../../packages/design-tokens/tokens.json), CSS
экспорт — [tokens.css](../../packages/design-tokens/tokens.css). В Native значения
px интерпретировать как проектные pt/dp и проверить на устройствах, не применять
масштабирование всей страницы как в review-каталоге.

| Токен                      | Значение                    | Применение                                       |
| -------------------------- | --------------------------- | ------------------------------------------------ |
| brandBlue                  | #0047BB                     | Главное действие, активная вкладка, номер заказа |
| brandOrange                | #FF671F                     | Акцент; тёмный текст вместо мелкого белого       |
| ink / muted                | #121A2B / #56647A           | Основной и вторичный текст                       |
| canvas / surface           | #EDF0F6 / #FFFFFF           | Фон и карточки                                   |
| success / warning / danger | #116D45 / #805100 / #B52E37 | Значение дублируется словом и иконкой            |
| darkCanvas / darkSurface   | #091120 / #141F32           | Базовые тёмные состояния; темы — tokens.theme    |
| darkText / darkMuted       | #F2F6FF / #A6B3C9           | Текст на тёмном фоне                             |

Текстовые пары проектируются на контраст не ниже 4.5:1, крупный текст — 3:1;
проверять фактические пары, а не насыщенность цвета на глаз.
[Основание: W3C SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
Это не заявление о полном соответствии всех интерфейсов WCAG.

Дополнительные палитры каждой поверхности хранятся в `tokens.theme`, семейства
шрифтов — в `tokens.font`. CSS-переменные имеют префикс поверхности. Исключение
текущего бэк-офиса описано ниже: его локальная тема уже отличается от
исторической тёмной палитры в общем пакете.

## Размеры и типографика

По решению владельца от 8 сентября 2026 в текстах всех интерфейсов используется
обычный дефис `-`: в предложениях, диапазонах и пустых значениях. Примеры:
`Первая вершина - Фурманова`, `10:00-00:00`, `6-9 минут`, баланс `-`.

Сетка отступов: 4/8/12/16/20/24/32/40/48/64. Основной текст mobile 16,
заголовки 24–32, промо 48; служебные подписи 12–14. Включены исходные WOFF2:
Jost/Manrope для mobile, Montserrat/Golos Text для kiosk/POS/KDS/display,
Inter для backoffice. Проверить отрисовку на устройствах, включая
казахские Ә Ғ Қ Ң Ө Ұ Ү Һ І. Логотип не заменять набранным текстом.

| Поверхность | Контрольный макет              |    Цель касания | Особенности                                         |
| ----------- | ------------------------------ | --------------: | --------------------------------------------------- |
| Mobile      | 390×844; проверить 320/360/430 |             ≥48 | Safe areas, dynamic type, нижние вкладки            |
| Kiosk       | 1024×1366 portrait             |             ≥64 | Крупные карточки/CTA, корзина, приватность сессии   |
| POS         | 1366×900                       |             ≥56 | Постоянная корзина, периферия, клавиатура и тач     |
| KDS A/B     | 1440×900                       |             ≥64 | Номер 48+, позиции 22+, отступы для быстрых касаний |
| Display     | 1920×1080                      |    нет действий | Номера 96; расстояние/overscan проверить в зале     |
| Backoffice  | 1440×960                       | ≥44, mobile ≥48 | Таблицы со своим scroll, фильтры, редакторы         |

Радиусы: control 12, card 20, sheet 28, pill 999. Не применять карточки ради
декора к каждой строке плотной таблицы. Большой номер заказа — моноширинные
цифры. Денежная сумма не переносится между числом и ₸, не обрезается многоточием.
Полные модификаторы, аллергены, финансовые ошибки и причины остановки не обрезать.

## Текущий бэк-офис: уточнение от 8 октября 2026

Это расширение существующего кабинета, а не новая дизайн-система для всего
PickChick. Источник реализованных значений -
[workspace.css](../../apps/backoffice/src/workspace.css), подключённый после
[styles.css](../../apps/backoffice/src/styles.css). Изменение общей палитры
mobile, kiosk, POS, KDS и display из этих правил не следует.

- Навигация и ссылки используют синий #0047BB, основное действие - оранжевый
  #FF6900 с тёмным текстом #231307. Фон кабинета #F5F7FB, боковая навигация
  #04143A, поверхности форм и журнала белые; основной текст #15233D,
  вторичный #5D6B82, границы #E0E6EF.
- Сохранён Inter. Заголовки рабочего кабинета: h1 1.85rem, h2 1.35rem,
  h3 1.08rem; при ширине до 800 px h1 1.65rem. Поля используют 1rem,
  финансовые поля 0.95rem; денежные значения и таблицы - табличные цифры.
- Рабочая сетка: навигация 232 px и гибкая основная колонка; до 1100 px
  навигация 208 px. При ширине до 800 px кабинет переходит в одну колонку,
  а меню раскрывается кнопкой в потоке страницы. Это актуальное поведение
  бэк-офиса вместо ранее описанного drawer на границе 768 px.
- Кнопки и поля имеют радиус 8 px, основные панели и журнал - 12 px.
  Панели плоские, разделяются фоном и границей; выбранный финансовый отчёт
  отмечен синей линией. Эти значения уточняют общую шкалу для бэк-офиса.
- На мобильной ширине до 800 px кнопки, основные пункты навигации, переключатель
  меню, поля и select получают высоту области нажатия не меньше 48 px.
  Журнал сохраняет собственную горизонтальную прокрутку. При открытом
  финансовом редакторе скрыты недоступные фильтры периода.

**Разделение бренда и состояния.** Синий обозначает навигацию, оранжевый -
действие; смысл финансового состояния остаётся в подписи, а не только в цвете.
**Читаемый журнал.** Суммы выровнены вправо и не теряют валюту при переносе;
плотные строки не превращаются в отдельные декоративные карточки.

Общий `tokens.theme.backoffice` и таблица исторических референсов по-прежнему
описывают прежнюю тёмную поверхность. Они не являются источником текущей темы
кабинета; их миграция требует отдельного согласования общей области токенов.
Объём визуальной проверки и статус выпуска записаны в
[backoffice-mobbin.md](../operations/backoffice-mobbin.md). Наличие этих правил
не означает приёмку владельцем, проверку всего бэк-офиса или успешный выпуск.

## Доступность и адаптация

Логический порядок фокуса: заголовок → контекст → поля → основное действие →
вторичные действия. После перехода в Native/web объявить заголовок; после ошибки
перевести focus к summary либо ошибочному полю. Focus не запирается в баннере.
Модальные окна в реализации должны возвращать focus инициатору, Escape закрывает
только безопасные диалоги; подтверждённый платёж не отменяется закрытием окна.

Экранная клавиатура не перекрывает CTA; используются safe-area insets, scroll
и native keyboard avoidance. Для 200% текста строки растут, операции остаются
доступны; таблицы переходят в списки или собственный горизонтальный scroll.
Для мобильного управляющего целевой принцип - summary перед таблицей;
актуальные границы и раскрытие навигации реализованного бэк-офиса описаны выше.
Review-каталог масштабирует фиксированные макеты только для просмотра — это не responsive
реализация будущих Native/React-приложений.

Анимации: feedback 120 мс, sheets 220 мс; при reduced motion без перемещения.
Готовность/оплата не меняются анимацией. Звук KDS ограничивается по повтору и
может отключаться; визуальный признак остаётся. QR и финансовые поля не
объявлять вслух целиком. VoiceOver/TalkBack и оборудование ещё не проверены.
