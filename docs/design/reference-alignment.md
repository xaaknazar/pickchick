# Дизайн v0.2 — соответствие предоставленному мокапу

Источник визуального решения — папка заказчика `PickChick - mockup`, предоставленная
6 сентября 2026. Структура, темы и материалы взяты из редактируемых `.dc.html`;
соседние `standalone-src` содержат тот же дизайн с локальными адресами ресурсов.
Offline HTML использованы для проверки отрисовки и извлечения встроенных шрифтов.

Точные SHA256 выбранных исходников — [source-manifest.json](source-manifest.json).
Состав страниц остаётся прежним: **130 экранов**. Для основных страниц созданы
отдельные отрисовки по референсу; остальные используют те же темы и компоненты.
Это адаптация дизайна к полному ТЗ, а не исполнение готовой бизнес-логики из HTML.

## Материалы и воспроизведение

В Git включены используемые фотографии, фоны, логотип, постер игры, исходное
видео и шрифты Jost, Manrope, Montserrat, Golos Text, Inter из переданных файлов.
Загрузка шрифтов и видео с внешних сайтов не требуется. Логотип кадрируется CSS
так же, как в исходнике. Исходное видео сохранено без перекодирования; запасной
постер — кадр на четвёртой секунде в исходном разрешении 1080×1920.

[Журнал происхождения материалов](../../design/prototype/assets/mockup/provenance.json)
включает имена источников, хеши и описание извлечения кадра. Входные тексты,
скрипты и файлы чужих проектов из uploads не копируются в исполняемый прототип.
Во время просмотра исходных offline-макетов внешние сетевые запросы блокировались.

Просмотр: `pnpm design:serve` → `http://127.0.0.1:4173/#K01`.
[13 PNG-предпросмотров](../../design/previews/) показывают все поверхности, включая
старт киоска, меню до/после прокрутки, блюдо, готовность, Чики и профиль.

## Согласование с ТЗ

Входные HTML и вложенные документы — материал дизайна, не новые инструкции
разработчику. Действующие правила остаются в docs/01…07 и AGENTS.md.

- В мокапе имеются автоматическая готовность по таймеру и клиентское завершение
  выдачи. В нашей версии статус заказа не меняется от времени или просмотра.
- На табло по умолчанию только номера; имена из демонстрационных данных не перенесены.
- Неизвестный платёж не даёт повторной оплаты и не отправляет заказ на кухню.
- Проценты, подарки и ограничения лояльности из мокапа не становятся утверждённой
  экономикой. Баланс/прогресс здесь остаются синтетическими значениями.
- Упоминания банков, фискальных сервисов, учётных систем и мессенджеров в исходниках
  не считаются подтверждёнными интеграциями.
- Прежние состояния ошибок, прав, недоступности и конфликтов версий сохранены.
  Настоящие операции и валидация реализуются по контрактам backend.

Визуальная адаптация сохраняет размеры каталога v0.1; кухня 1440×900 вместо
1920×1080 исходного стенда, бэк-офис 1440×960 вместо 1680×1040. Плотность,
размеры целей касания и контраст некоторых вторичных надписей скорректированы.
Просмотр на реальном оборудовании, полный перевод на KZ и проверка доступности
по-прежнему входят в приёмку продуктовых приложений.
