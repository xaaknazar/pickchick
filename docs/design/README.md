# PickChick — дизайн всех интерфейсов v0.2

23 сентября 2026: [UI/UX Pro Max + Impeccable - подключение и правила](ai-design-workflow.md)
и [первый разбор мобильного интерфейса](mobile-skills-review-2026-09-23.md).

Интерактивный каталог: **130 отдельных экранов** для приложения iOS/Android,
киоска iPad, Windows-кассы, двух кухонных экранов, табло и веб-бэк-офиса.
Это первая полная проектная версия для обсуждения и реализации, не рабочие
клиентские приложения и не утверждённый брендбуком финальный релиз.

```sh
pnpm design:serve
# Открыть http://127.0.0.1:4173/
```

Слева выбирается приложение и экран; поиск работает по всем приложениям.
Справа — назначение, связь с ТЗ, ограничения и состояния. «Фокус» увеличивает
макет. Прямая ссылка сохраняет экран и состояние: например,
`http://127.0.0.1:4173/#M14` или `/#M03?state=expired`.
Сам сервер слушает только localhost и отдаёт только дизайн и дизайн-токены.

## Основание и границы

Источник требований — docs/01…07, пять offline HTML заказчика и текущие уточнения.
HTML использованы как материалы дизайна; их платёжная логика не исполнялась и
не переносилась. Логотип, фото блюд и постер игры извлечены из manifest мобильного
макета без изменения байтов. [Происхождение и SHA256](../../design/prototype/assets/provenance.json).
Другой визуальный контент не скачивался. Отдельный брендбук в этой сессии пока
не предоставлен; запрошен путь. Цвета #0047BB/#FF671F и логотип сохранены.
В версии v0.2 визуальный источник — полная предоставленная папка PickChick - mockup;
темы, шрифты, видео и компоновка приведены к ней.

Цены, метрики, номера и остатки синтетические. Фото и названия в макете не
заменяют утверждённый каталог блюд, КБЖУ, аллергены или прайс. Экономика Чиков,
игровые награды, адрес, часы работы, legal copy и KZ-переводы требуют согласования.
RU/KZ есть в архитектуре и на табло; переключатель языка в этом прототипе
показывает примечание, а не заявляет наличие полного казахского перевода.

Внешние интеграции и backend не вызываются. Платёжные результаты выбираются
явно через панель просмотра событий. Сохранение/отправка/отзыв/возврат показывают
демонстрационную обратную связь, а не выполняют операции. QR декоративный,
не содержит токена. Результат игры не меняет баланс. Табличная пагинация и
фильтры статусов демонстрационные; текстовый поиск по видимым строкам работает.

Полный функциональный UI, React Native/Electron/React-компоненты, переводы,
сквозная интеграция с backend и тесты на оборудовании остаются этапами реализации.
Приоритет P0/P1 в каталоге — порядок детализации дизайна, а не самостоятельное
изменение согласованного релизного scope. P2-функции собственной доставки и
отложенного заказа в checkout не добавлены.
