# Исправление переноса мобильного мокапа

7 сентября 2026. Причина замечания заказчика: первая Expo-версия использовала
правильные Jost/Manrope и синюю тему, но переносила часть экранов через
упрощённые общие компоненты. Композиция витрины, профиля, событий и карточек
отличалась от предоставленного HTML. Каталог из 35 страниц и успешный переход
между ними сами по себе не подтверждают визуальное соответствие.

## Источник и правила

Визуальный источник — [сохранённый оригинал](../../design/reference-source/mobile-v2.html.txt)
из последней папки заказчика. Он сверялся с локально отрисованным bundled offline
HTML. `design/prototype` остаётся проектным каталогом дополнительных состояний,
но не подменяет этот оригинал при проверке мобильной композиции.

| Область              | Перенесено в Expo                                                                                                                                |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Витрина M06          | Центрированная шапка; белый выбранный сегмент; исходное видео и плавный градиент; «Комбо недели» по центру, отступ 164; hero 660 при ширине 402  |
| Чики в меню          | Перекрытие hero на 104; исходный skyline.svg, карточка 20, кольцо 52, заголовок 17                                                               |
| Каталог              | Непрерывные разделы, закрепляемые категории; карточки 22 с фото 112; белая цена и синяя «Выбрать»; квадратная сетка по два столбца               |
| Корзина              | Общая синяя кнопка-пилюля 54/27 над tabs на четырёх основных вкладках; компактная шапка, карточки товаров 22/фото 80, инсет-блок Чиков/промокода |
| Карточка M07         | Квадратная обложка, видео Pick Combo из оригинала, заголовок Jost 700/30, описание 14,5; фиксированное добавление                                |

| События M26          | Заголовок 34, skyline-стрик, афиши 212/26 с текстом поверх; отдельные иллюстрации Pick Man и Pick Run                                            |
| Кошелёк M23          | Синяя фирменная карточка баланса, две полупрозрачные метрики, уровни и строки операций                                                           |
| Входная страница M01 | Фирменный узор, крупный логотип, исходная композиция и текст первого слайда                                                                      |

Кнопки паузы фонового видео удалены в native mobile, работающем web-киоске
и обеих витринах проектного каталога по прямому указанию заказчика.
Фоновое видео остаётся без звука; сокращение анимации и уход в фон
останавливают воспроизведение. Обложка сохраняется до первого кадра/при ошибке.
Кнопка паузы интерактивной игры к этому изменению не относится.

Гостевой профиль показывает неизвестный баланс/уровень и недоступный QR внутри
исходной композиции. Реальные бонусы, SMS и Kaspi не имитируются. Образцы баллов
и стрика остаются только в явно отмеченных страницах просмотра дизайна.
Pick Run открывает имеющуюся локальную тренировку; Pick Man обозначен как будущая
игра. Серверные цены TEST-каталога и бизнес-состояния не заменялись числами из HTML.
Остальные страницы расширенного ТЗ сохраняют собственные состояния, которых
не было в исходнике; абсолютное попиксельное совпадение всех 35 страниц не заявляется.

## Проверка и найденные дефекты

- Браузерный тест `tests/mobile/browser_mockup_fidelity.py`: исходная геометрия,
  переключение категорий с длинным названием точки на 320/402, сохранение
  горизонтальной позиции, квадратные фотографии и два столбца, уменьшение анимации.
  Все HTTP-ответы подменяются локальной read-only фикстурой.
- `tests/operations/layout_regression.py`: корзина/tabs и нижние действия на
  коротких, узких и повёрнутых окнах; отсутствие кнопки паузы киоска.
- XCUITest: реальные Release-переходы menu → product → cart → обратно,
  скриншоты первичных экранов, нижние кнопки и клавиатура, общий обход 35 страниц.
- На первом нативном прогоне обнаружен вызов `pause()` после автоматического
  release VideoPlayer при закрытии товара. Управление воспроизведением переведено
  в эффект состояния фокуса; cleanup больше не обращается к освобождённому объекту.
- При визуальной проверке также исправлены перекрытый заголовок категории,
  сброс горизонтальной прокрутки и наследование фиксированной высоты фото сетки.
- GitHub CI выявил гонку Expo Video web: `play()` прерывался `pause()` при
  навигации, а Promise оставался необработанным. Для web добавлен отдельный
  адаптер с обработкой прерывания, обложкой при отказе и системной остановкой.
  Регрессия воспроизводится детерминированно; проверка `pageerror` не ослаблена.
  Нативное тело плеера из опубликованной сборки 3 сохраняется.

Фактические результаты, пары оригинальных/нативных скриншотов и пределы проверки
сохранены в [UI-протоколе](../../tests/operations/verification-mockup-fidelity-2026-09-07.md).
Сборка 0.1.0 (3) назначена внутренней группе TestFlight;
[подтверждение Apple](../operations/mobile-testflight.md#выпуск-010-3--исходная-композиция-и-витрина-без-паузы).
