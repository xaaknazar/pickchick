# Сенсорные размеры кассы 0.4.6

По поручению владельца проверены кнопки на разных разрешениях моноблоков.
На физической кассе отдельная проверка в интерактивной Windows-сессии дала
1366×768, рабочую область1366×728 и96 DPI (100%). Данные служебной SSH-сессии
не использованы как размер реального экрана.

## Матрица проверки

Проверены CSS-области853×480,910×512,1024×600,1024×768,1093×614,
1280×720,1280×800,1280×1024,1366×705,1366×768,1440×900,1536×864,
1600×900,1920×1080,2560×1440 и3840×2160. Включены уменьшенные рабочие
области, соответствующие масштабированию125/150%. Это эмуляция компоновки,
а не физическая проверка всех моделей моноблоков или калибровки сенсоров.

20 экранов/состояний ×16 размеров =320 проверок. Проверены10127 экземпляров
элементов управления: минимум44×44 CSS px, доступность центра кнопки после
прокрутки и отсутствие переполнения текста у простых кнопок. Проверка не
объявляет все элементы одновременно видимыми: длинные списки/окна прокручиваются.
Дополнительно выполнены реальные touch-tap на переключателях категорий.

Экраны: PIN, начальный остаток, меню, модификаторы, соусы и напитки большого
набора, движение денег, комментарий, имя гостя, передача, успех, заказы,
карточка заказа, стоп-лист и срок стопа, смена, сводка закрытия,
пересчёт денег, причина расхождения, PIN начальника при закрытии.
Снимки при910×512,1024×600,1366×768 и1920×1080 сохраняются в локальном
выводе теста; исходный макет дизайнера не изменён.

## Исправления

- Комментарий ограничен экраном; его содержимое прокручивается отдельно,
  заголовок и подтверждение доступны. Клавиатура перестраивается по ширине.
- «Промокод» и «Блокировать» больше не сжимаются до обрезанного текста.
  У нижней панели появились явные классы адаптации; повтор сетевого статуса
  скрывается на узких экранах, статус остаётся наверху.
- На низких экранах компактнее фотографии/карточки и кнопка передачи,
  при этом зона касания сохраняется.
- На низких экранах список заказов расположен перед сводкой и имеет
  достаточную высоту; действия доступны с прокруткой таблицы.
- В больших наборах колонки соусов/напитков перестраиваются по месту;
  кнопки количества не сжимаются.

Браузерный сценарий на изолированной PostgreSQL с отключённым WAN прошёл:
PIN, смены, движение денег, корзина, потерянный ответ, кухня, табло и закрытие.
Настоящий Electron-сценарий восстановления заказа и fullscreen тоже прошёл.
Сборка, проверка Python-синтаксиса и форматирования выполнены.
Установка0.4.6 на оборудование фиксируется отдельно в протоколе выпуска.
GitHub Actions для исходного коммита завершились с failure; Windows-job
не выполнил ни одного шага. Это отдельное ограничение CI, его прохождение
не заявляется на основании успешных локальных проверок.
