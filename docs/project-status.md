## Следующий этап 1 — фундамент разработки

Запланировано, ещё не реализовано:

1. Monorepo с пакетным менеджером, зафиксированными версиями и общими настройками.
2. Центральный TypeScript/NestJS API и каркас локального edge.
3. Локальная инфраструктура PostgreSQL/Redis и воспроизводимый запуск.
4. Первые миграции организации/точек/устройств/каталога.
5. Общие API/event contracts, синтетические данные и минимальные проверки CI.
6. Проверяемый первый сценарий согласно Gate A/B roadmap.

Код приложений, CI/CD, production-инфраструктура и банковские интеграции пока
не созданы. До прерывания предыдущей задачи выполнялось только обследование
рабочей папки и доступных инструментов.

## Внешние зависимости

Доступы Kaspi mobile и Smart POS; выбор и автономный режим зарегистрированной
ККМ; API Яндекс Еды Казахстан; характеристики оборудования точки; согласование
бонусной экономики и складских правил. Полный список —
[реестр решений](06-mockup-review-and-decisions.md).
