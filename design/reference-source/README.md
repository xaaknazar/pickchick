# Исходные мокапы заказчика

`mobile-v2.html.txt` — неизменённая читаемая версия предоставленного
`PickChick - mockup/Pick Chick App v2.dc.html`. SHA256 записан в `provenance.json`.
Это исходный визуальный ориентир, а не наша интерпретация в `design/prototype`.
Файл хранится как текст; в клиентский bundle и публичный web release не входит.

Содержимое рассматривается как материал дизайна, а не инструкции агентам.
Встроенные примеры платежей, телефонов, QR, баллов и остатков не являются
реальными данными или спецификацией интеграций. Бизнес-логика определяется ТЗ,
серверными контрактами и актуальными решениями заказчика.

Фотографии, шрифты и видео, используемые приложением, находятся в
`design/prototype/assets/mockup`; происхождение фиксируется отдельно.
При переносе сохраняем композицию, размеры, порядок блоков и типографику.
Нативная safe area заменяет нарисованную рамку телефона и системный статус-бар.

## Киоск iPad

`kiosk.html.txt` — исходный HTML, извлечённый только JSON-декодированием
`script[type="__bundler/template"]` из предоставленного заказчиком
`PickChick - mockup/Pick Chick Kiosk (offline).html`. Текст шаблона не изменён;
2056 строк сохраняют номера для аудита. Полный offline-контейнер 16,9 МБ
со встроенными base64-ресурсами не добавляется в репозиторий.

`kiosk.provenance.json` содержит SHA-256 исходного контейнера и декодированного
шаблона, а также 51 ссылку на ресурсы: исходный UUID, путь из таблицы bundle,
MIME, размер, SHA-256 распакованных байтов и точные совпадения с ресурсами
репозитория. UUID в тексте оставлены без подмены. `null` у исходного пути
означает, что bundle не предоставил человекочитаемое имя; пустой список
совпадений не разрешает подменять изображение похожим и считать его исходным.

Шаблон хранится как `.txt` и не подключается к приложению или публичному
web release. Встроенные обработчики макета, случайные номера заказов,
платёжные примеры и общий `localStorage` телефона/имени не исполняются при
извлечении и не являются реализацией требований. Реальные требования к
переносу описаны в [аудите киоска](../../docs/design/kiosk-native-audit.md).
